# 文风基因组(STYLE GENOME)· 设计规格

> 由 5 视角头脑风暴 workflow 综合而来。这是实现的权威依据。

## 分层(genome_layers)

### lexicon — L1 词汇分层指纹(Lexical Strata · 带密度/搭配/触发语境)
**捕获**:把全书实词按语义场分层(器物机械/不可名状克苏鲁/宗教赎罪/感官身体恐怖/军事侦探/维多利亚日常质感/情绪),每层给:标志词表 + 高频搭配(如『血肉』+蠕动/挤出/愈合)+ 该层在每种 scene_type 下的相对密度(归一到千字)+ 文白雅俗坐标 + 触发语境。核心改进:从基线的扁平 8-15 词升级成『带配比、分场景、带搭配』的调色盘,LLM 知道每层词在哪类场景该撒多浓。

**管线**:复用 _sampling 但改成**分桶取样**(关键):用 chapter_beat.scene_type 把章分成 打斗/悬疑惊悚/煽情/日常/转场 等桶,每桶取 representative_chapters(按 tension 降序)5-8 章全文(chapter_text)。两段式:① 逐桶 MODEL_FAST 扫——prompt='你是语料文体学家,给定本桶(scene_type=X)若干章原文,列出反复出现的实词归入预设语义场,每词给出现频段(high=本桶半数章/mid/low)与2-3条逐字共现搭配,只收原文真出现的、不许编词',输出 per-bucket 词表。② 聚合 MODEL_STRONG 跨桶合并同义、按 (词在桶内频段命中数 × 桶字数) 估算每层 density_by_scene[scene]=每千字次数、给文白雅俗坐标与触发语境。density 用确定性代码兜底:对每层 signature_words 在该 scene 桶原文里 str.count 求和 / 桶总字数 × 1000,避免 LLM 估值漂移。落 analysis_card('genome.lexicon')。

**输出形状**:`{strata:[{layer:'cthulhu_unnameable', gloss:'不可名状/腐化', signature_words:['秘血','蠕动','不可名状'], collocations:[{head:'秘血',with:['的加持','加持下的力量']}], density_by_scene:{combat:0.7,horror:1.0,daily:0.1}, register_coord:{wen_bai:'书面偏雅',ya_su:'中'}, trigger_context:'妖魔出场/身体异变时'}], diction:'文白相间偏冷硬', avoid:['气息','波动','能量'(廉价网文词)]}`

### syntax — L2 句式构式库(Syntactic Templates · 带槽/触发/频率上限/滥用红线)
**捕获**:抽作者反复用的可填空句式骨架:渐进恐怖长句『随着[X变化],[Y结果]』、转折句『[主体][动作],可[反应]』、比喻定调独段、推理列举-推断链、弱断言句式(似乎/仿佛/如同)。每个骨架给:槽位模板 + 触发 scene_type + 频率档 + 3条逐字实例 + 制造的效果 + 滥用红线(数值化:似乎/仿佛≤N处/千字,堆叠即网文腔)。把基线 sentence_rhythm 一句话升级成可直接套用的填空骨架库,并显式区分『招牌句式』与『该避免的滥用句式』。

**管线**:按 scene_type + plot_function 双键分桶(推断链集中在 payoff/推理桶、渐进长句集中在 escalation/horror 桶)。**直接复用 craft 26 类里已切好的逐字片段**(category in {rhythm, combat, interior, climax, dialogue_subtext})做输入,省 token、保证逐字。MODEL_STRONG prompt='你是句法文体学家,找作者反复使用的句式构造(是可复用骨架不是单句内容),抽象成带槽模板如"随着[X],[Y]",给模板名/骨架/触发场景/3条逐字原句/此构造的效果;另列弱断言句式(似乎/仿佛/如同)的本作真实用法与滑向网文腔的滥用界线'。弱断言频率用确定性代码统计:全书 chapter_fts 里 re.findall('似乎|仿佛|如同|宛如') 计数 / 总字数 × 1000 得 authentic_rate,LLM 只判定 overuse_redline 倍数。落 analysis_card('genome.syntax')。

**输出形状**:`{templates:[{id:'horror_progression', skeleton:'随着[X变化],[Y结果发生]', effect:'不可抗身体恐怖渐进', trigger_scenes:['悬疑惊悚','大高潮'], freq_band:'high', exemplars:['随着血肉的蠕动,一枚又一枚弹头从伤口被挤出'], misuse_redline:'每段≤1次'}], hedge_usage:{terms:['似乎','仿佛','如同'], authentic_rate_per_kchar:2.4, overuse_redline:'连续句首滥用或>3倍均值=网文腔,禁止'}, rhythm:'打斗短句爆破/忏悔长句', paragraphing:'独句成段做停顿', punctuation:'……独段定调,破折号转折'}`

### rhetoric_voice — L3 修辞与叙述声音(Metaphor 本体→喻体映射 + 叙述距离/侵入/FID/心理动词)
**捕获**:合并两个相邻提案以去重。修辞侧:比喻本体→喻体映射偏好(人→兽、声音→温度天气、状态→宗教意象)+ 喻体语义场分布 + 通感/叠词(呆呆/死死/缓缓/反反复复)/反复/留白的配比与触发。叙述声音侧:叙述距离与自由间接引语(他似乎/在X看来)、叙述者评议侵入(格言式断言+第二人称泛指)、信息揭示顺序(先感受后事实)、高频心理动词表(似乎/觉得/不禁/迟疑/暗喜/鬼使神差)、反问设问习惯。这是『通过怎样的比喻/叙述角度表达风格』的答案,基线的 tropes 和 narrative_pov 完全没碰语言修辞与叙述者癖性层。

**管线**:煽情/悬疑惊悚/人物刻画桶权重高(比喻密度大);叙述距离侧重 is_protagonist_pov=1 章 + pov_event 切换点取样。复用 craft 的 signature_metaphor / motif / interior / monologue 片段。两 prompt 合一次 MODEL_STRONG 调用:'(a)抽所有比喻逐条记[本体]→[喻体]并归入语义场(动物/天气温度/宗教/机械/自然),统计最爱映射方向;(b)列通感/叠词/反复/留白逐字例;(c)分析叙述距离是否大量贴人物内心(FID)给例、是否跳出评议给例、信息揭示顺序、高频心理动词、反问设问,只据原文给锚点'。叠词/省略号独段用确定性代码全书计数补强。落 analysis_card('genome.rhetoric')。

**输出形状**:`{metaphor_map:{favored:[{tenor_class:'人物状态',vehicle_class:'野兽',rate:'high',exemplars:['像没目的的野狗迎风狂奔吐舌']}], vehicle_dist:{动物:0.4,天气温度:0.2,宗教:0.25,机械:0.15}}, reduplications:['呆呆','死死','缓缓'], rhetoric_mix:{simile:'high',reduplication:'high',ellipsis_para:'medium',enumeration:'high'}, narrator:{distance:'紧贴内心高频FID', fid_examples:['在乔伊看来…简直和中了大奖一样'], intrusion:{present:true,style:'格言式断言+你泛指',examples:['这是个不可控的男人,你难以推测他下一步']}, reveal_order:'先察觉后给事实', psych_verbs:['似乎','觉得','不禁','迟疑'], rhetorical_q:'中频,用于自我说服与推理转折'}}`

### atmosphere — L4 类型质感配方(Genre Carriers · 蒸汽朋克/克苏鲁/维多利亚/侦探 手段→实现→例证→剂量)
**捕获**:把每种类型质感拆成可调用的『美术+音效+道具+行为+恐惧手法』表。蒸汽朋克:道具(黄铜齿轮/煤气灯/铆钉义肢)+器物语法角色(主语/工具/喻体)+能源机械隐喻模板+器物密度。克苏鲁:回避命名/侧面烘托/感官失序/理智代价/异常日常化各手法是否用+强度+关键句式+黄金律(永不正面写本体只写反应代价)。维多利亚:分阶级对话语域(敬称/迂回/俚俗)+时代符号物+阶级并置对照。侦探:线索类型(真/红鲱鱼/暗)+fair-play+三方信息差。每条 carrier 带类型标签 + 逐字证据 + 每千字剂量。正面补『蒸汽朋克/克苏鲁具体通过怎样的词汇/描写/行为/景物表达』。

**管线**:高氛围取样:scene_type∈{悬疑惊悚,大高潮} 且 tension≥70 章 + worldview_reveal 命中超自然概念章。复用 craft 的 object/scene_env/scene_place/sensory/suspense/climax 片段(不重新逐字抽,只做载体归类)。MODEL_STRONG 分类型抽:'这是同属[蒸汽朋克+克苏鲁]的代表原文,拆解营造该质感的具体手段:①专有词汇按类归纳并标高级用法 vs 要避免的廉价替代;②感官调色板(视/听/嗅/触各举原文例)及触发场景;③反复意象母题及大致密度;④该世界观下人物标志行为;⑤恐惧/神秘的表达技法(直写还是侧写)逐字举证'。剂量字段用确定性代码补:carrier 词在对应 scene 桶 str.count/千字。落 analysis_card('genome.atmosphere')。

**输出形状**:`{genres:[{genre:'克苏鲁', techniques:[{means:'回避命名',how:'只写人的生理性恶心与认知崩解,不给怪物长相',intensity:'high',examples:['…不可名状,他干呕着别开视线'],density_per_kchar:0.6}], sensory_palette:{sight:['惨绿','非欧几何'],sound:['低频嗡鸣'],smell:['腥湿']}, motifs:[{image:'义体黄铜',density_per_kchar:0.8}], behavior_paradigms:[{situation:'理智流失',manifestation:['反复呢喃','机械重复动作']}], golden_rule:'永不正面写本体,只写反应与代价', lexicon:{do:['秘血','腐化'],avoid:['气息','波动']}}]}`

### scene_routine — L5 场景调度子程序(Scene Decoding · 切入机位→节拍序列→详略预算→POV距离→收尾钩子)
**捕获**:把每种 scene_type 抽成一份可执行『分场拍摄剧本』,正面补缺陷#3#4。每类场景给:opening_cut(切入机位:景物定锚/人物动作/对白先行/内心反应/感官异象/信息陈述,带分布概率+镜头距离+第一感官通道+入戏速度)、beat_sequence(4-8个有序节拍,每拍 beat_function[建立/挑动/对抗升级/转折/兑现/回落/留扣] + camera_move + 该拍字数占比 word_share)、detail_budget(动作/对白/景物/内心/信息五分类百分比 + 哪拍放慢哪拍快切 + 直白度0-100)、pov_blocking(叙述距离 + 是否中途越轴切POV)、exit(收镜方式 + 与下章衔接剪辑 + hook_grammar[信息揭示/危机逼近/反转/情感悬置/新登场] + 触发句式模板)。

**管线**:升级现有 sample_by_scene:每类取**完整场景全文**(不截断,顺序是命门)而非 head+tail,优先高潮/cliffhanger 强章,每类6-10场。MODEL_STRONG 逐场抽 per-scene JSON:'给一整场[X]戏全文,逆向写作程序:①从什么切入(机位枚举)+镜头距离+第一感官;②按时间序列出节拍数组,每拍={beat_function枚举,camera_move,one_line,word_share粗估百分比},覆盖全场不重叠;③detail_budget五分类百分比+哪拍放慢哪拍略写;④pov_anchor+叙述距离+是否中途越轴;⑤exit_type+cut_to_next+hook_grammar+把触发句抽象成填空模板;逐字举证'。聚合阶段:对每 scene_type 把多场的 opening_cut 算分布、beat_function 序列做 bigram 转移概率、detail_budget/word_share 求均值。落 analysis_card('genome.scene_routine')。

**输出形状**:`{routines:[{scene_type:'大高潮', opening_cut:{dist:{人物动作:0.62,景物定锚:0.21},dominant:'人物动作',shot_distance:'中景',first_sensory:'视+听',entry_speed:'in-medias-res'}, modal_beat_sequence:['建立','挑动','对抗升级','转折','兑现','回落'], beat_transition:{对抗升级:{转折:0.55},转折:{兑现:0.7}}, beat_word_share:[12,18,15,8,30,17], detail_budget:{action:45,dialogue:10,scenery:8,interior:12,info:5,slowed_beat:'转折'}, bluntness:72, pov:{distance:'内聚焦贴身',mid_scene_switch_rate:0.1}, exit:{type:'特写定格',cut_to_next:'硬切',hook_grammar:'危机逼近',hook_template:'就在[X即将Y]时,[Z]出现了'}, sample_chapters:[210,455]}]}`

### macro_arch — L6 宏观架构(伏笔plant→payoff图 + 信息预算曲线 + 张力控制律 + POV调度策略 + 章型模板库)
**捕获**:把零散点升维成关系/序列/转移,这是『片段法抓不到的整体结构』。五件子产物:①伏笔账本(plant手法+伪装强度+中途reinforce+payoff手法+跨度+情感回报,聚合中位跨度/长线比/伪装手法分布);②信息预算(逐章 info_load + 载体[对话/情节体验/文献/旁白直述/环境暗示] + 同一设定拆成几次小剂量投喂的drip序列 + infodump率);③张力控制律(把曲线参数化:上升斜率/峰后回落幅度/峰间距随进度漂移/喘息章规律,不是单一均值);④POV调度策略(离开主角的触发→去向→停留时长→回归触发 + 交叉剪辑节律);⑤章型模板库(把全书章聚类成8-15种章型,每种给 macro-block 序列[承接钩→场景A→转场→场景B→内心→章末钩]+各块篇幅占比+所属scene_type+信息/伏笔操作)。

**管线**:大部分确定性代码 + 局部 LLM。①伏笔图:**复用既有 foreshadowing 表**(planted_chapter/resolved_chapter/type/status 已有)+ worldview_reveal,补抽『伪装强度/reinforce节点/payoff手法』——对 plot_function=payoff/twist 的章做第二遍回指匹配 prompt='这是兑现/反转章,下面是此前所有 open 伏笔清单,判断本章兑现/强化了哪几条,给 payoff_method 与 emotional_payoff';跨度/中位/分布用 SQL 聚合。②信息预算:逐章 MODEL_FAST(可与伏笔阶段一合并一次调用省钱)记 info_load/carrier/dose/is_dump;drip 序列用代码把同名 concept 跨章 dose 串起来。③张力控制律:**纯代码**在 chapter_beat 全序列做峰检测/上升斜率/回落比/峰间距分位数/按 book-position 分桶趋势;LLM 仅给 profile_type 一句注解。④POV策略:**纯代码**聚合 pov_event(away_ratio/median_span/return_trigger 分布)+ 对齐 tension 曲线看非主角POV的功能位置。⑤章型模板:对代表章 MODEL_STRONG 切 macro-block 序列(每章4-8块,标 role/len_pct/scene_type/info_op),再用代码按序列相似度聚类成N种章型。落 analysis_card('genome.macro_arch')。

**输出形状**:`{foreshadow:{threads:[{id:'th_真名',plant_chapter:12,plant_method:'角色随口提及',disguise_strength:85,reinforces:[{chapter:140,how:'侧面再提'}],payoff_chapter:410,payoff_method:'反转揭示早已知情',span:398,emotional_payoff:92,plant_type:'设定'}],stats:{median_span:120,long_line_ratio:0.3,disguise_dist:{},reinforced_ratio:0.45}}, info_budget:{info_load_curve:[...],infodump_ratio:0.06,carrier_dist:{情节体验:0.5,对话:0.3,旁白直述:0.08},drip:{序列体系:{doses:[20,15,30,35],chapters:[3,9,40,88],installments:4}},rule:'大设定拆≥3次跨≥30章,旁白直述<10%,单章info_load软上限40'}, tension_law:{profile_type:'慢热多峰',rise_slope:{median:18,iqr:[10,28]},fall_after_peak:{median:-35},peak_interval:{overall:14,by_quarter:[22,16,10,7]},breather_rule:{after_big_climax_within:1.4,ratio:0.12}}, pov_policy:{away_ratio:0.22,switch_policies:[{trigger:'制造信息差',to:'反派',median_span:2,return_trigger:'主角侧危机',often_before:'大高潮'}],cross_cut:{cut_every:3,cut_on_cliffhanger:0.7}}, chapter_archetypes:[{name:'对峙升级章',freq:0.18,block_sequence:[{role:'承接钩',len_pct:8,scene_type:'转场'},{role:'对话试探',len_pct:25},{role:'冲突爆发',len_pct:35},{role:'内心抉择',len_pct:18},{role:'反转钩',len_pct:14,hook_type:'反转'}],info_ops:['中段埋1伏笔','末段提醒旧伏笔'],tension_shape:'中→峰'}]}`

### transition — L7 转移模型(状态转移张量 · LSTM/Transformer 类比的『递进规律』层)
**捕获**:把已有逐章离散状态序列升级成带方向、带触发条件、带二阶依赖的转移模型。状态空间=scene_type × plot_function × tension档(低/中/高/峰) × POV(主角/非主角)。产出:①一阶转移矩阵(从S_t到S_{t+1}的概率)+ 二阶高频三连模式(铺垫→喘息→大高潮 的 lift);②每个高信息量转移点的触发类型(外部威胁/谜底揭示/新势力登场/承诺兑现/情绪爆发/时空切换/内部抉择);③章末钩子→下章开篇的衔接转移(hook_type→next_opening 分布)。改进现有 transition 层:现状只有 scene_type 单维一阶矩阵,缺触发条件、缺二阶、缺 hook→open 衔接。这层是用户 Transformer/LSTM 诉求最直接的落地,可当采样器驱动大纲生成。

**管线**:①**纯代码**从 chapter_beat 全序列统计:用 zip(seq,seq[1:]) 建一阶 Counter 矩阵归一成概率(现有 matrix() 函数已有,扩展到联合状态键);二阶用 zip(seq,seq[1:],seq[2:]) 统计三连频次并对比独立基线算 lift;hook→open 用 (beat[i].hook_type, beat[i+1].opening_cut) 配对(opening_cut 来自 L5)。②触发标注:仅对『高信息量转移点』(张力跃迁>25 或 plot_function 切到 twist/payoff)调 MODEL_FAST,prompt='给第N章与N-1章节拍摘要,本章 scene_type 从X跃迁到Y(张力a→b),判定推动跃迁的触发类型(枚举)+一句逐字依据,严格JSON',零原文成本(只喂 summary)。落 analysis_card('genome.transition')。

**输出形状**:`{states:['铺垫|低|主角',...], transition_1st:{'铺垫|中|主角':{'小高潮|高|主角':0.41,'转场|低|非主角':0.22}}, transition_2nd:[{seq:['铺垫','喘息','大高潮'],lift:1.8}], most_likely_next:{'铺垫':'小高潮'}, trigger_taxonomy:{'铺垫→小高潮':{top_triggers:[{type:'外部威胁',freq:0.5}],typical_setup_span:2}}, hook_to_opening:{'危机':{'人物动作':0.6,'感官异象':0.2}}, note:'值=转移概率,可据此让大纲生成器按作者递进倾向采样下一章状态'}`

## 基因组产物 + 渲染(genome_artifact)
最终产物是一个机器可读的 StyleGenome JSON + 一份可渲染的 system-prompt spec,二者同源。

【一】存储:沿用现有约定,每层落 analysis_card(category='genome.<layer_id>'),assemble() 汇成一行 category='genome' 的总卡,形状:
{book_slug, version, built_at, layers:{lexicon, syntax, rhetoric, atmosphere, scene_routine, macro_arch, transition}(各层即上面 output_json_shape), fingerprint_vector:{...}(见下), system_prompt:'渲染后的字符串'}。

【二】fingerprint_vector(新增的关键:把基因组压成可计算向量,供 eval 闭环用):由各层确定性聚合而来,形如 {lexical_density:{cthulhu:1.0,religion:.5,...}, hedge_per_kchar:2.4, reduplication_per_kchar:1.2, metaphor_vehicle_dist:{动物:.4,...}, detail_budget_by_scene:{大高潮:{action:.45,...}}, bluntness:72, infodump_ratio:.06, tension_profile:'慢热多峰', scene_transition_topk:{...}, hook_grammar_dist:{...}}。这是一组可逐维做 KL/余弦 diff 的标量+分布,是『风格判别器』的数值底座。

【三】渲染成喂给别的 LLM 的 spec:render_spec() 升级为**两档输出**——
(A) 静态 system-prompt(软用,人类可读,直接拼进 build_writer_system(mimic_guide=spec)):分节『用词调色盘(分层+每场景密度配比)/句式骨架库(填空模板+频率上限+滥用红线)/修辞与叙述者操作手册/类型质感配方(每质感一张卡+黄金律)/分场景调度手册(每 scene_type:切入分布→节拍链→详略预算→POV距离→收尾钩子模板)/宏观编排纪律(伏笔中位跨度/反信息倾倒红线/张力控制律/POV调度规则)/场景递进倾向表』。这一份替换现有 style_genome.render_spec 的扁平输出,接到 draft.pipeline 已有的 build_writer_system(mimic_guide) 注入点,零改 writer ReAct 链。
(B) 动态 per-chapter brief(硬用,可选,接到 outline.refine):把 L7 转移张量当采样器——给定当前章状态,按 transition_1st 采样下一章的 scene_type/plot_function/tension/POV,取该 scene_type 的 L5 调度卡 + L6 章型模板 + 本章须执行的伏笔记忆操作(plant/reinforce/payoff 待办栈)+ L4 题材剂量配额,组装成一份『本章导演 brief』(shot-list 大纲),再交 writer 逐块填词。这正是 ML 类比里『可运行的状态机』:基因组既能存 JSON、又能被另一个 LLM 当采样策略逐章驱动。

渲染原则(回应基线缺陷):①一切定性挂频率/密度/区间;②一切范式带1-3条逐字锚点(slot-filled exemplar);③按 scene_type 路由载入对应语体/调度参数,把『风格』从单一常量升级成可路由状态机,根治『全程一个腔』。

## 评测方案(eval_protocol)
目标:证明 StyleGenome spec 比基线(StyleProfile 单段总结 + 几段 scene_exemplars 当 few-shot)更能让 writer『仿得像』。三层评测,从主观到客观:

【对照设置】固定同一题材/同一章大纲(从《余烬之铳》取若干代表章的 outline,覆盖打斗/悬疑惊悚/煽情/转场各类),用同一 writer 模型、同温度,A 组=基线 few-shot,B 组=genome spec(静态 system-prompt 档),C 组=genome 采样 brief(动态档,可选)。每组对每个 outline 各生成1章。隐藏组别。

【评测一 · LLM 评委盲评(主观维度)】用 MODEL_STRONG 当评委,给『原作真实该章原文 + A/B/C 三份生成稿』(打乱顺序),按以下维度各 0-100 打分并要求逐条给逐字依据:(1)词汇语域吻合(克苏鲁/宗教/器物层是否在对的场景以对的浓度出现);(2)句式节奏吻合(招牌句式命中/弱断言是否超标网文腔);(3)修辞与叙述声音吻合(喻体取向、FID、叙述距离);(4)类型质感到位度(蒸汽朋克/克苏鲁是否『画面里真有』而非贴标签);(5)场景调度吻合(切入机位/节拍序列/详略/收尾钩子是否像作者打法);(6)章末钩子强度;(7)整体『像不像同一作者』总分。复用项目已有 STYLE_REVIEWER_SYSTEM 的思路(以原作片段为唯一标尺),扩成7维评分卡。每个 outline 跑 N 次取均、消组别偏置。

【评测二 · 指纹自动对账(客观维度,本方案的杀手锏)】用**完全相同的抽取 schema**(L1-L7 的同一套 prompt)去扫 A/B/C 三组生成稿,得到各自的 fingerprint_vector,与原书 fingerprint_vector 逐维算偏差(密度向量用 KL/余弦,标量用相对误差)。输出一张『文体偏差报告』:如『克苏鲁层密度低40%、弱断言句式超标3倍、大高潮场详略预算 action 比原作低15pt、章末钩子 hook_grammar 分布偏离』。预期 B/C 组在多数维度上偏差显著小于 A。这把『像不像』从人工感觉变成可计算的目标函数——同一把抽取的尺子反过来量产出物,得到一个 genre/style fidelity score(零新模型零新基建,全是已有组件)。

【评测三 · 消融】对 B 组逐层关掉(去掉 L5 调度/去掉 L4 题材配方/去掉 L1 密度配比),看评委分与指纹偏差各掉多少,验证每层的边际贡献,指导取舍与优先级。

【闭环回灌(对接已有写→审环)】评测二的偏差报告每条带可执行修正指令(如『把不可名状层密度拉到每千字4-6处』),直接回灌进 writer system 或下一轮 brief,接现有3审(style/plot/consistency)gate,让仿写从开环 few-shot 升级成带文体损失的闭环收敛。

## 实现顺序(build_order)
- P0 取样基建升级(1-2天,零LLM):把 _sampling 从全局 spread_sample 改成『scene_type×POV 分桶 + 完整场景取样(不截断)』,新增 fingerprint 确定性聚合工具(词密度 str.count/千字、弱断言/叠词/省略号独段计数、张力峰检测/斜率/回落/峰间距分位)。这是 L1/L5/L6/L7 共同的地基,先打。
- P1 纯代码层先落地(1天,零成本高回报):L7 转移模型的代码部分(一阶/二阶矩阵+hook→open,扩现有 matrix())+ L6 的张力控制律与 POV 调度策略(纯 chapter_beat/pov_event 聚合)+ L6 伏笔图(直接复用既有 foreshadowing 表 SQL 聚合)。这些不烧 token、立刻产出可见结构,先验证管线。
- P2 微观范式三层(2-3天):L1 词汇分层(分桶取样+density兜底)、L2 句式构式库(复用 craft 片段省token)、L3 修辞+叙述声音(合并去重)。这三层直接补基线最薄的语言指纹,渲染收益最快。
- P3 场景调度子程序 L5(2-3天,最重但回报最大):完整场景取样+逐场抽 per-scene JSON+聚合成每 scene_type 调度卡。正面补缺陷#3#4,是 spec 里最可执行的『怎么写一场X』。
- P4 类型质感配方 L4(1-2天):分类型抽 carrier 表+剂量。正面补缺陷#2(蒸汽朋克/克苏鲁怎么表达)。可复用 craft 的 object/scene_env/sensory 片段。
- P5 宏观架构补 LLM 部分 L6(2天):信息预算逐章扫(与伏笔阶段一合并调用)+ 章型模板聚类 + L7 触发类型标注(只喂 summary)。补齐宏观层。
- P6 组装与双档渲染(1-2天):升级 assemble()/render_spec() 输出 fingerprint_vector + 静态 system-prompt 档(接 build_writer_system mimic_guide)+ 动态 per-chapter brief 采样器(接 outline.refine,可选)。
- P7 eval 闭环(2-3天):搭 A/B/C 三组对照生成 + 7维LLM盲评卡(扩 STYLE_REVIEWER_SYSTEM)+ 指纹自动对账(同schema扫产出稿做KL/余弦diff)+ 消融。产出 fidelity score 并回灌写→审 gate。

- B 的系统性优势集中在四点:① 词汇/设定语域复用准(黑天使/圣银/净焰/秘血/符文回路/逆模因武装),浓度与位置都对;② 场景调度更接近作者的多机位/分幕结构(双机位切分还原'两个污染源并发');③ 叙述声音的'概念高于血肉'神学化弱断言('不是人类意志,是规则…如同重力,如同熵增');④ 专名锚点列举(旧敦灵街道/洛小姐/赫尔克里)这一作者签名手法被复刻。
- A 的系统性短板:倾向第一人称贴身+生理恐怖/灾难奇观大片,机位单一拉远,叙述距离过近;频繁出现翻译腔/科学词(熵增/安魂曲/上帝视角)与口语脏话('你他妈疯了'),破坏原著克制庄重的语域;器物/设定层常缺席或贴标签;钩子偏轻(数据汇报/能力炫耀式收尾)。
- 两稿共有的剧情/打法偏移:都把原著'群像失控→宗教战争/政教斗争→主角对峙仅露半句'的多机位调度,改写成更安全的双人摊牌或正向'实验成功/融合成功'收束;均未复现'对话快速抛设定'的信息节奏与'洛伦佐被【间隙】感染、握不住剑'的 FID 共情机制;都丢失文艺复兴权谋语境与师徒决裂内核。

### 基因组优势
- 词汇/设定语域命中率高且位置准:稳定复用专名与设定词(黑天使/圣银/净焰/秘血/符文回路/逆模因武装/侵蚀阈值),浓度对、位置对,是 lexicon 维全场领先的主因。
- 场景调度更贴作者打法:能还原原著的多机位/分幕骨架(如双机位切分还原'两个污染源并发'、'展示记忆→对话揭示理念'的同构结构),scene_routine 维优势最大(+10.75)。
- 叙述声音复刻到位:用'概念高于血肉'的神学化弱断言('不是人类意志,是规则…如同重力,如同熵增,如同死亡本身'),FID/抽离感更接近原著冷峻好议论的全知声音。
- 章末钩子更接近原著悬置式收尾(黑天使非人视线如解剖刀划过、'……活人'低声重复),形式与质地双近。
- 复刻作者签名手法:专名锚点串列(旧敦灵街道/洛小姐/赫尔克里)、长逗号流水句、三联弱断言('没有光,没有声音,没有方向')、抽象概念喻体('白色染上灰'同源),整体黏稠语感更像同一作者。
- 克苏鲁/侵蚀层做成'画面里真有'的弥散不可名状感('深渊本身睁开了眼睛'),而非器械参数贴标。

### 基因组不足与改进
- 语域穿帮:B 在煽情场直接写'第三次世界大战/核冬天/意识形态'等现代地球词,撞破原著文艺复兴政教+蒸汽朋克的虚构外壳。改进:在 genome spec 增设'禁用词表/anachronism 黑名单'(现代政治科技词→映射到在地虚构等价物),写后用快审 agent 跑一遍语域穿帮检测。
- 网文化升级公示残留:B 仍夹带量化播报('神经同步率97.3%/侵蚀度控制在安全阈值内/第一个主动驾驭')。改进:spec 显式标注'本作者不议论/不播报数据',将数值改写为感官化弱断言或干脆删去;在 rhetoric/voice 维加'去仪表盘化'约束。
- 自拆比喻的网文腔:'那不是比喻。'这类自我点破式强调原著不会用。改进:spec 加一条'禁止自拆比喻/禁止 meta 强调',让喻体直接成立。
- 排版碎片化:B 出现大量单句独立成段('他低头。''记得黑暗。''而他……'),呈短视频节奏,与原著长段群像铺陈冲突。改进:在 spec 注入'段落颗粒度/平均句段长度'目标值,绑定具体场景类型(群像高潮→长段铺陈;近距独白→中等),并加分段密度校验。
- 群像多机位仍丢失:四场里 B 普遍把原著指挥室群像对白线(亚瑟/红隼/塞琉/盖革器/二次炮击/临界值30%-60%/华生)压成双人或独白,只用一句带过宗教战争/群像。改进:spec 增加'必含机位清单(named POV roster)+每机位最小篇幅配额',强制多机位扫描;并要求'用对话快速抛设定'的信息节奏指标。
- 标题格式不合规:'第四幕·七十七章'不符原著'第七十四章 劳伦斯'。改进:把章节标题模板做成 spec 硬约束(格式串 + 章号连续性校验)。
- 前半段仍偏第一人称生理特写,细节密度高于原著克制。改进:spec 设'生理细节预算上限',超限时降密度、上移到概念化恐怖。
- 情节方向偏移(共性):B 也把高压未决态写成'融合成功'正向收束。改进:在 brief→spec 落地时显式锁定'本段结局态(未决/崩溃/反转)',并在阶段复审 gate 校验情节方向是否与目标态一致。
- 可执行优先级:先补两条最高 ROI 的 spec 约束——(1) named POV roster + 篇幅配额(直击 scene_routine,A/B 共同最弱维);(2) anachronism/数据播报黑名单(直击 B 唯一的硬穿帮)。这两条预计能把 B 在 scene_routine 和 lexicon 上再拉开与 A 的差距,并堵住 B 当前最明显的失真。

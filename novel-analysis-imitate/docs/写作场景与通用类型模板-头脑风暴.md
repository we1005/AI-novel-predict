# 写作场景与通用类型模板 · 头脑风暴

> 本文是 7 个棱镜(场景分类 / 类型模板 / 多作者融合 / 可控性 / 评估重构 / 架构落点 / 反直觉跨界)的综合沉淀。**只做头脑风暴,未验证**;不是最终方案。后续可验证项见第 9 节。

---

## 1. 核心 reframe(用我们自己的话讲清)

1. **目标从"指纹"换成"做菜法"。** 我们不再追求还原某个作者的风格指纹,而是萃取**某一类**写作的**可调菜谱**:意象池 + 修辞手法集 + 句式节奏曲线 + 禁忌项 + 调味旋钮。"文风基因组 7 层"是"还原某个人",对本项目是副产品;真正的一等公民是**类型基因(genre gene)**。

2. **"像不像某作者"基本不要,改问三件事:对不对题、塌不塌方、够不够新。** 流水线长篇网文"看起来像那一类、能自由发挥"就够;即便存在上帝视角的相似度标准也没用——逐字相似度在高分区与"好"反相关(最像的就是换了人名的原文)。

3. **要的是"最大公约数 + 辨识度",不是"求平均"。** 类型模板不是把 N 个作者揉成一锅没味道的粥。正确动作是:找出 N 个作者**都在做、但各用不同私货实现的那个共同动作**,把"动作/手法"留下、把"私货/词面"剥掉,再给动作配一组可替换的"实现槽"。

4. **杂糅多作者多作品是常态,不是例外。** 甚至可以"克苏鲁 70% + 维多利亚 20% + 蒸汽朋克 10%"连续加权,或孵化"种田文 × 宇宙恐怖"这种没人写过的杂交新物种。融合要在"特征 + 适用条件"层做,不在裸特征层做——条件让冲突从"打架"变"分工"。

5. **"贴原作者续写"是另一个项目的事,且只是很细很少的一个挡位。** 在本系统里它退化为"在纯类型模板上叠加一个可选的、可调浓度的作者风味包",而非单独起炉灶。

## 2. 写作场景全景(去重归并)

把零散的 26 条场景归并成 7 大类。每类一句"它要什么、不要什么"。

### A. 类型模板的提炼与运营(项目主战场)
- 具体场景:类型风格通用模板提炼(克苏鲁+维多利亚+蒸汽朋克抽成模板)、跨书素材拼贴(各取最强场景套路拼超级套路库)、类型杂交新物种孵化(种田文×宇宙恐怖)、配方保存复用("我的私房风格")、风格体检卡(给文本出"风格成分表")。
- **要**:类型的最大公约数 + 辨识度,跨多人去个性化,可命名、可版本、可复用。**不要**:锁定某一个人的指纹、求平均成平庸。

### B. 即取即用的氛围/素材生成(一次性、即弃也行)
- 具体场景:氛围腔调命题作文(一段蒸汽朋克雨夜独白)、意象/修辞套件即取即用(20 个不可名状意象)、命题短篇/单元剧(3000 字反转克苏鲁)、节庆营销命题速产、批量备选生成(给我 10 个版本挑)。
- **要**:腔调/氛围标签命中度、新鲜度、约束满足、多样性。**不要**:对标任何具体人、收敛(批量场景反而要刻意发散)。

### C. 已有内容的改造与升格(输入是用户的文本)
- 具体场景:半成品升格润色(大白话草稿升档)、反风格去味(去网文味/翻译腔/爹味)、题材跨语境本地化(西幻改东方玄幻语感)、腔调档位标尺化(地摊/正常/文艺/史诗四档)、难度受众适配(青少年/成人/硬核老白)。
- **要**:保留剧情信息量、按"质量/腔调/受众"刻度迁移、带 diff 可对照。**不要**:模仿谁——锚点是抽象坐标轴不是人。

### D. 手法与结构的迁移(剥离文风,拿骨架/招式)
- 具体场景:跨题材手法移植(武侠"招式留白"搬进科幻枪战)、节奏/爽点结构模板(打脸-反转-升级节拍表)、同题材换皮量产(修仙→星际→西幻铺章)、多视角多腔调复调写作。
- **要**:手法本身/叙事结构学/爽点工程学的稳定复现,跨域嫁接丢原语境。**不要**:同域复制、绑定原作者的内容。

### E. 从零起盘的原创(没有可贴的源)
- 具体场景:原创世界观从零起盘(一句点子推自洽世界+开篇)、设定集→正文扩写(干设定长成沉浸场景)、灵感破冰/反套路提案(给我三个反预期写法)。
- **要**:自洽性、延展性、设定忠实度、新颖度/反预期。**不要**:对标外部作者(文风随便挑)、收敛到成熟模式。

### F. 长篇工程与一致性(自我对标,不是他人)
- 具体场景:长篇一致性护栏(50 万字后文与前文自己一致)、配方传递(书级→卷级→章级→段级覆盖)、风格漂移监控。
- **要**:与作品自身前文一致、防自我漂移、可锁定核心特征。**不要**:任何外部作者参照——锚点是作品自身。

### G. 元能力/工具与教学(诊断、约束游戏、可解释)
- 具体场景:写作教学拆解示范(带批注的范文+手法讲解)、写作约束游戏(Oulipo 式硬约束)、风格体检诊断。
- **要**:可解释、约束满足下的创造力、教具价值。**不要**:产出像谁——目的是让用户学会某类手法。

## 3. "通用类型模板"该长什么样

### 3.1 总观点:类型模板 ≠ 作者模板求平均
- **类型基因 = 不变的"做法/手法/约束"**(怎么写恐怖、永不正面写本体)。
- **作者基因 = 这个做法的一种"具体填充"**(用"秘血/净焰"还是"旧日支配者"填"不可名状"这个槽)。
- 正确形态 = **手法骨架(共性) + 可插拔实现槽(每槽给多家作者样本作选项,而非求平均)**。

### 3.2 部件清单(9 个部件 + 3 个贯穿元数据)
1. **意象库 Image Bank**:按"意象家族"组织的树(母意象 + 物化清单 + 禁忌物),每条带 `genre_tag` / `universality` / `slot_options`。是 craft 的 object/scene_env/sensory/motif 的跨书归一升级版。
2. **修辞手法目录 Rhetoric Catalog**:把修辞当可调用招式,每招给 触发场景/输入/喻体类/效果/剂量上限/滥用红线/正反例。**只存招式 + 喻体类分布,不存具体喻体词**(词去意象库取)。
3. **母题与套路库 Trope Library**:类型级叙事 trope(学者堕入真相、发明反噬…),每条给 典型节拍序列/常见变体/反套路出口/跨几个作者出现。这是单纯文风层抓不到的"故事级类型基因",当前最弱、需新抽。
4. **语域与腔调 Register & Voice**:语体坐标 + 叙述者人格 + 多声部语域表(贵族/仆役/学者/工人)。存坐标+范围+禁区,不存招牌句。
5. **感官调色板 Sensory Palette**:五感各给主色/辅色/禁色 + 跨感联觉规则。单列因为它是最快见效的氛围开关(改五感比改结构便宜)。
6. **节奏与桥段骨架 Pacing & Beat**:张力曲线形状 + 场景调度套路 + 转移倾向。存曲线形状+相对比例,数值留作可调参数。
7. **世界观元件 Worldview Components**:可拼装的设定零件(力量体系/社会元件/冲突引擎/in-world 文本模板),每件给**显式槽位接口契约**才能拼装。
8. **命名风格 Naming Engine(全新)**:人名/地名/术语/章节标题格式的生成规则。**只存音系/构词/格式规则(共性),不存具体名字(私货)**。命名是作者最强签名,剥离高危区。
9. **禁忌与边界 Taboo Set(提级为独立件)**:把散落各层的 avoid/redline 集中成可校验清单(黄金律、语域穿帮黑名单、反网文腔红线、anachronism 黑名单)。它是类型纯度守门员,最适合编译成"写后快审 agent"规则源。

**3 个贯穿元数据**(每个部件都挂):`universality` 共性度(0-100,剥离核心标量)/ `provenance` 来源链(来自哪几本书,用于追溯和反平均)/ `dosage` 剂量(每千字密度/频率上限/触发场景路由)。

### 3.3 类型基因 vs 作者基因 的剥离(8 招,可叠加)
| 招 | 做法 | 判据 |
|---|---|---|
| 1 交集即共性 | N 本各跑 genome,逐部件做集合运算 | `universality=出现书数/总书数`,≥0.5 进骨架 |
| 2 抽象阶梯 | 把不同词抬高一层使其重合("秘血/净焰"→`物质异变`) | 抽象层进骨架,原词降级为 slot_options |
| 3 频率指纹差分 | 算类型质心 + 单本偏移 | **低方差维=类型基因(固定),高方差维=作者基因(留旋钮)** |
| 4 留一交叉验证 | 每次留 1 本当陌生作者测试集 | 能预测留出书的=共性,预测不了的=私货 |
| 5 双标尺平行抽取 | 同段跑两 prompt(不提专名描述手法 / 找只属于该作者的标记) | A 进骨架,B 进 provenance |
| 6 反向消融 | 拿掉私货看类型是否还成立 | 拿掉后类型崩=类型基因;只是不像那作者=作者基因 |
| 7 语料外部锚 | 用类型百科共识当先验,N 本书填充/修正 | 命中先验+多书=高置信类型基因 |
| 8 污染检测 | 抓"显眼的私货被误当类型" | universality 低但典型性高 → 高亮人工确认;专名/人名/口头禅默认判私货 |

### 3.4 表示形态(三层 + 双档渲染)
1. **真相源 = TypeTemplate JSON**(机器存储、可 diff、可组合),即上述 9 部件,每条带 4 个贯穿字段。
2. **渲染层 = 两档 spec**:A 静态 system-prompt(直接拼进 `build_writer_system(mimic_guide)`,零改 writer);B 动态 per-chapter brief(用转移张量当采样器逐章出 shot-list)。
3. **运行时 = 可校验规则**:禁忌部件 + 剂量上限编译成写后快审,接 3 审 gate。

**可喂 LLM 的硬规矩(血换来的)**:一切定性→挂频率/密度区间;一切手法→带 1-3 条逐字 slot-filled 锚点;按 scene_type 路由载入参数;禁忌单独成节+编译成校验;命名/章标题做成硬约束串。

### 3.5 对照现有 7 层基因组的处置
- **直接复用(种子层)**:L4 atmosphere(本就按 genre 拆,是类型模板的种子)、L3 narrator、L7 transition(正好是组合时的采样器)。
- **改造(去私货化/加共性度/加槽)**:L1 lexicon→意象库/感官调色板;L5 scene_routine→跨书聚合成类型调度套路;L6 部分(张力律/信息预算)。
- **大改(私货重灾区,只留倾向)**:L2 syntax(只留长短句配比/弱断言范围/独段使用)、L6 伏笔/章型。
- **新增**:命名引擎、禁忌部件提级、跨书 trope 库、组合元数据层(genre_tag 命名空间 + conflict_resolution + mix_weight + 插槽契约)、universality/provenance 贯穿字段。

## 4. 多作者杂糅策略

### 4.1 为什么会变成粥(对症下药)
四个根因:**算术平均陷阱**(峰值被磨平,最有味道的恰是极端值)、**维度对冲**(A 长句 B 短句平均成中等句长,两家命都丢)、**指纹串味**(把洛氏专名搬进狄更斯市井段,像 cosplay 串场)、**采样偏置**(某本体量大/片段多,无意识主导味道)。

### 4.2 加权与取舍:凭功能贡献度,不凭作者均权
给每条候选特征打 4 分:**类型识别度**(一眼认出这是克味?高分设骨架级)、**可迁移性**(脱离原书还能用?低分判指纹要剥离)、**复现成本**(别的 LLM 能否稳定复现?低分降级为可选风味)、**冲突度**(与已选互斥?高冲突进仲裁)。
三原则:**留极端弃中庸**(灵魂在尖峰,平均即谋杀)、**按层差异化权重**(越宏观越要单家主导求连贯,越微观越能多家并存求丰富)、**少数服从最强样本而非多数样本**(频率≠价值,1 本书的尖货只要 rep-score 高就收)。

### 4.3 冲突消解五策(按优先级,建"冲突卡"沉淀)
1. **条件化分流(首选,最不损味)**:长句绑"氛围/独白"场景,短句绑"动作/对白交锋"场景 → 张弛有度而非精神分裂。
2. **层级错位**:A 家语域用在叙述层,B 家用在对白层(市井俚语活在角色嘴里,学术腔活在叙述者声音)。
3. **主从仲裁**:节奏/视角/时态/人称这类全局结构不能并存,选一家做主、其余降维成局部手法。
4. **频谱化**:对立维度(华丽↔冷峻)做成 0-100 旋钮,默认值放某处但暴露给用户调。
5. **升维统合(最高级)**:两家看似冲突,往上抽一层是同一意图的两种实现(凡尔纳"机械礼赞"+洛氏"机械恐惧"=都在写"人对超出自身尺度之物的眩晕"),把上位意图写进模板,两走向都列为可选落点。

每条冲突生成"冲突卡":`{维度, A方主张, B方主张, 消解策略, 触发条件/边界}`。

### 4.4 去个人指纹 + 声音调和
**剥离指纹清单**:专属生造词/神话私货(抽象成"不可发音的他者命名法")、口头禅式高频词(降频或换近义集)、特定时代地域硬指代(抽象成"工业都市阶层落差套路")、个人化标点癖(保留"停顿密度"功能量不保留具体符号)、签名式开篇结尾公式(学功能结构不学字面外壳)。
**调和声音的关键一招**:设定**统一的隐含叙述者人格**——不是 A+B+C 拼贴,而是"一个人学过 A、B、C 之后形成的自己的腔调";所有借来的技法经这个虚拟叙述者的口重新发声。配合**语域基线归一化**(像音频 loudness normalization,避免一家突然变响)、**过渡黏合剂**(风味切换处预置过渡句型)。

### 4.5 防串味手法
带标签存储不带标签调用(来源只用于审计/调权,不泄漏到成稿)、共识做地基尖货做点缀、**配额制**(每千字最多 1 处某家招牌)、同类槽位内互斥(一段只准一家)、代表作做锚平庸段降权、正交分解再重组、**负面清单**(明确"这类风格绝不做什么")。

### 4.6 三个配方示例
- **配方 A(洛夫克拉夫特+狄更斯+凡尔纳)**:上位母题=工业都市里渺小市井众生撞见超出理解的造物,奇迹与恐怖同源。骨架:狄更斯主导节奏/群像(最扛长度),洛氏主导题材内核/红线(不给廉价解释),凡尔纳供奇观揭幕钩。风味:三库意象叠加。冲突卡:机械礼赞 vs 机械恐惧→升维统合,用"认知崩塌烈度"旋钮随章拉升完成翻转。去指纹:不出现"克苏鲁"原名、架空工业城、伪科学精密感替代真考据。
- **配方 B(废土末世通用模板)**:上位母题=资源即道德、生存即叙事。骨架:网文式快节奏+资源/等级升级曲线。冲突卡:重战斗爽感 vs 重人性灰度→频谱化"爽度↔灰度"旋钮。去指纹:不绑任何具体 IP 专名。
- **配方 C(东方修仙+西方剑魔+克苏鲁)**:上位母题=追求超凡力量者终将触碰不该触碰的真理。骨架:修仙境界递进做升级引擎,克味"知道越多越危险"做暗线,奇幻公会/任务做支线。漂亮的升维案例:修仙"玄而又玄"留白 ⊃ 克味"拒绝描述"→合并成"至高之物不可直述"模块。三档语域按场景切(术法半文言/日常白话/禁忌冷峻学术)。

## 5. 灵活运用与可控性

### 5.1 心智模型:模板是一台"调音台",不是一段 prompt
音色=意象/修辞包,推子=旋钮,预设=bundle,自动化轨=按章自适应曲线,干/湿比=风格强度 vs 自由发挥。**所有复杂度藏在音色和预设里,暴露给用户的只有推子和一排预设按钮**——用户不必懂"基因组 7 层"。

### 5.2 旋钮:分三档暴露,别一次给 40 个
- **一线(默认露 5-6 个)**:风格强度、阴郁度/基调、句式节奏、修辞浓度、对白密度、信息节奏。
- **二线(按当前模板题材动态浮现)**:加载克苏鲁模板时出现"维多利亚度/身体恐怖浓度/不可知感/机械蒸汽感/宗教仪式色彩";换仙侠模板则换成另一组。**二线旋钮随音色包打包**。
- **三线(高级抽屉)**:长短句具体比例、段落长度、感官通道配比、喻体取材域白/黑名单、视角粘滞度、专名密度上限、禁忌清单。

两个让旋钮"可控而非玄学"的细节:① **旋钮要有锚点示例**——拖动时旁边实时从 craft 库检索一条该刻度的代表句("哦原来这么稠");② **旋钮间显式标注耦合**——拉到互相打架的组合给柔性提示("当前是密集爽点+绵长长句,二者偏冲突,偏向哪个?")。

### 5.3 预设 / 模块拼装
- **出厂预设**(降冷启动):「雾都阴影」「血肉献祭」「齿轮与谎言」「理智崩坏」,各对应一组旋钮+音色+负面清单,也作为"看别人怎么调"的范例。
- **预设进阶玩法**:A/B diff(雷达图叠加看差值)、Morph 插值(60%A+40%B 做情绪渐变)、继承/覆盖(书级默认+章级只覆盖几个旋钮)、导出分享(.style.json)。
- **模块化拼装(LoRA 思维)**:做很多小而专的可热插拔件——意象包/修辞包/节奏包/基调包,UI 上是三个下拉槽位,各自可换可叠。混搭杀手锏=跨题材换件("克苏鲁意象包 + 武侠修辞包 + 爽点密集节奏")。兼容性提示:🟢推荐/🟡实验/🔴打架,**不禁止只提示**。
- **包可成长(回流机制)**:写出满意段落→一键"沉淀进我的私有包",抽取其物象/句式追加。用得越久越像"我的"。

### 5.4 两根正交滑杆:风格强度 vs 自由发挥度
- **风格强度**=模板特征在成稿里的密度/覆盖率。**自由发挥度**=模型偏离配方去自创的许可。
- 四象限(做成一键象限选择器):`严谨仿写` / `带感发挥`(推荐默认,网文长篇甜区) / `轻点缀` / `自由创作`。
- 注入实现:风格强度→控制范例条数+约束措辞强度;自由发挥度→控制配方是硬约束还是软建议、是否开放创新条款。**UI 只暴露两根滑杆,背后是 prompt 模板的参数化拼装**。这是可控性的本质:把人类语义旋钮编译成 LLM 能吃的约束。

### 5.5 注入点(越上游越粗,越下游越细)
| 阶段 | 注入什么 | 形态 |
|---|---|---|
| arc/整本推演 | 宏观架构包+信息节奏旋钮 | 影响 phase 划分、全书钩子分布 |
| outline/章纲 | 场景套路包+对白密度+节奏包 | 注入"本章风格意图" |
| draft/成稿 | 意象包+修辞包+词汇句式层+全部一线旋钮 | 拼成 system-prompt + 检索范例 |
**关键认知**:节奏类旋钮要在 arc/outline 早注入(节奏是结构问题),意象/修辞类在 draft 注入(质感是字句问题)。很多工具只在 draft 塞风格,导致"句子很有味但整章节奏还是平的"。
**预设传递链**:书级→卷级→章级→段级临时强调,在哪级动旋钮就只影响那级及以下。

### 5.6 长篇自适应(可控、可关、可改)
- **章节风格曲线(自动化轨)**:在全书时间轴对几个关键旋钮打关键帧,中间插值(阴郁度 开篇40→危机70→高潮95→尾声60)。用户只打几个关键帧,几百章自动铺开。
- **章节类型→预设自动路由**:每章打类型标签,建"类型→推荐预设"映射,outline 阶段自动套用(可一键否决)。
- **段级临时强调**:编辑器选中一段右键"此处身体恐怖拉到 90",只重生成这段,不污染章级。
- **防漂移护栏**:基线锚定(几个🔒全书不可动的核心特征,自适应碰不到)+ 风格漂移仪表盘(把每章实际旋钮值画曲线,异常跳变高亮回溯)。

## 6. 评估重构:从"相似度"到"适配度"

### 6.1 为什么相似度是错的尺子
三类错:**奖励抄袭惩罚创造**(逐字相似度最高=换人名的原文,与"好"在高分区反相关)、**测了不存在的目标**(类型味是几十作者交集,拿单作者当 ground truth=拿一个样本定义一个分布)、**可被廉价刷分**(模型一旦知道在比相似度,最优解就是搬高频词复用句式骨架→越优化越像复读机)。
**新总纲**:目的达成度(对了吗)+ 不塌方(没犯错吗)+ 不重复(够新吗)。"像不像某源"只在"贴原作者续写"一个场景里作为**约束项**(非目标项)出现。

### 6.2 三层框架 + 一个元开关
- **L1 类型契合(对题)**:类型隶属度、命题贴合度(锚点要"化入场景"非"贴标签",显白名词直出扣分)、世界观自洽度。
- **L2 文本质地(写得好)**:画面感、**意象密度×新鲜度**(`新鲜度=没见过×还说得通`,新鲜但不通归零)、节奏可读(只设健康区间不设标准答案)、**AI 腔检测/de-slop**(万能转折、"不是…而是…"上瘾、每段升华小作文味——常开,是"像人"的底线)、整体追读欲(有否决权)。
- **L3 工程健康度(产得稳,长篇专属)**:**抗自我重复**(本书已用资产指纹库跨章查重,长篇第一杀手"瞳孔一缩/倒吸凉气")、多样性、连续性、套路率(双刃,符号由场景决定)、**批量稳健性/失败率**(量产语境方差比均值重要)。
- **元开关**:三层优先级随场景翻转,不存在一套放之四海的权重。

### 6.3 分场景的成功标准(核心)
| 场景 | 北极星 | 关键 | 对源相似度 | 尺子一句话 |
|---|---|---|---|---|
| A 原创世界观(主战场) | 类型隶属×追读欲 | 重权意象新鲜/画面/自洽;套路率减分 | **完全不看** | 像不像这类里一本好看的**新书** |
| B 换皮量产 | 模板符合×批量稳健 | 抗自我重复/多样性升到最高;新增跨产物去重 | 模板内相似度要高、产物间相似度要低 | 批量看会不会被看穿是同一个模子 |
| C 贴原作者续写(很细很少) | — | 连续性升为硬约束 | **唯一让相似度作约束存在**,用区间命中(落区间满分,超出才扣),不"越像越好" | 老读者会不会以为是原作者更新的 |
| D 命题氛围段 | 命题贴合×画面感 | 不看连续性/抗重复;最适合做 50 张回归基准 | 不看 | 闭眼,画面立住了吗、有没有一句记得住的意象 |

**精髓:同一维度跨场景符号会翻转**(套路率、相似度),这正是"不同尺子"的本质。

### 6.4 何时不需量化(靠人感)
创作探索/找调性期、样本极小(三五段)、拍板取舍最后一步、指标饱和却读着别扭、高语境强个人风格的"魂"层、**指标开始反噬创意时**(为刷新鲜度写怪话、为压 AI 腔写得干巴)。
**贯穿原则**:量化的正确定位是"产线门禁 + 回归报警 + A-B 裁决",**不是"创作罗盘"**;"什么是好"永远先由人定义、再用指标近似。

### 6.5 替代相似度的"对的尺子"
- **盲测 A-B + 真原文暗桩**:把人写原著/我们生成/baseline 混进去盲评,**挑不出生成段才是赢**——测"像不像人/像不像这个类型"而非"像不像某指纹"。
- **风格区分度(可判别性)**:轻量判别器能否把"克苏鲁版"和"武侠版"分开,分得开=风格有效成立。
- **模板自洽度(风格 Linter)**:成稿对自己模板 token 的遵守率(负面清单命中/BPM 偏离/意象和谐度)。
- **新鲜度/反套路度**:与"该类陈词滥调清单"的 n-gram 重合率,越低越好。
- **最低质量门 gate**:不触发负面清单、不掉出节奏区间、判别器能认出风格→放行;否则打回。把"够"操作化。

## 7. 架构落点

### 7.1 现状定性:作者基因做透了,缺的是类型层
`fused_style/fused_worldview/fused_technique` 三件套**已是"类型基因"的胚胎**(多本同类书蒸馏出统一手册),但被困在 `project_slug`(一次性副产物)。本次升级本质=**把它提级+命名+版本化成 `genre_template` 一等资产**,补齐意象/修辞/母题三库,再用旋钮接进早已存在的三个注入点。

### 7.2 三层数据模型(下层覆盖上层)
- **L1 GENRE GENE 类型基因(跨作者跨书可复用资产)**:`genre_template` 实体,含 atmosphere/scene_routine/macro_arch/transition(可迁移四层取共性)+ imagery_lexicon/rhetoric_catalog/trope_library(新增三库)+ syntax/lexicon 共性版(去签名后的交集)。
- **L2 AUTHOR GENE 作者基因(现有 genome)**:用途①=L1 的原料(N 作者→蒸馏类型基因);用途②=可选叠加调味("克苏鲁类型 + 七成爱手艺味")。**去签名化是 L2→L1 的核心算子**(取交集/众数/频次阈值)。
- **L3 WORK INSTANCE 作品实例(compose 虚拟书 + OutlineRun)**:选 1 个 genre_template(必)+ 可选叠 0-1 个 author_gene(调味)+ 旋钮/预设覆盖。
> 这套模型解释了"杂糅多作者推模板"(L2×N→L1)和"贴某作者"(L3 叠单个 L2)为什么是同一台机器的两个挡位。

### 7.3 现有资产的复用/改造/新增
- **直接复用**:融合引擎(`_avg/_union` 三 builder,当类型模板构建器)、compose 克隆机制(承重墙,不动)、三种检索(push/agentic/vector,只需扩检索域参数 `corpus_slugs` 跨 N 本源书)。**agentic + 跨书语料池是杀手级组合**(模型按本章意图从所有同类源书自取最贴的真实段落)。
- **改造**:基因组 7 层按"可迁移 vs 作者签名"拆开存、拆开混合;新增 `render_genre_spec()`(在 `render_spec` 上砍作者签名层+加去签名取交集);craft 从 per-book 升到 per-genre 跨书聚合视图。
- **新增**:`genre_template` 表、三个跨书蒸馏 builder(意象/修辞/trope)、一个 trope 分析层 `layer_tropes`、组合元数据层(genre_tag 命名空间+conflict_resolution+mix_weight)。

### 7.4 数据模型(`genre_template` 表,放 projects.db)
关键字段:`genre_id`(稳定标识)+ `version`(自增,(genre_id,version) UNIQUE)+ `source_slugs_json`(蒸馏自哪 N 本,可追溯)+ `card_json`(子卡聚合,子卡可独立替换/各带 updated_at)+ `fingerprint_json`(复用 build_fingerprint 做版本 diff)+ `system_prompt`(预渲染产物,writer 直接吃)。
版本策略:不可变快照+自增 version;子卡级增量(改 trope 不必重抽 atmosphere);与 project 解耦(一个模板被任意多任务引用);`compose_book` 加列记录用了哪版(可复现)。

### 7.5 旋钮落点(渲染期/注入期/构建期三处)
氛围浓度→渲染期(golden_rules 取多少条+density 缩放);意象密度→注入期(density_target 乘系数);节奏→注入期(缩放 target_tension 曲线);POV 多机位→注入期(复用已有群像硬约束开关);作者风味比例→渲染期(决定 signature_block 注入多少);去签名强度→构建期(L2→L1 蒸馏的频次阈值)。
预设=旋钮快照,存 `card_json.presets[]`。

### 7.6 最小可用切片(MVP)vs 完整愿景
**MVP(复用 90%,新增 1 张表 + 2 个函数)**:① 建 `genre_template` 表(先只装可迁移四层+共性 lexicon/syntax);② `build_genre_template(genre_id, source_slugs)`(复用 fusion.build_all + 可迁移四层 + 新 `render_genre_spec`,几乎是已有代码重组);③ `seed_compose_from_genre`(照抄 `seed_compose_from_fusion` 改输入源);④ 检索扩 `corpus_slugs`;⑤ 跑通一条龙:3 本克苏鲁书→build→compose→write 5 章→人读"像不像这一类、能不能自由发挥"。**不碰 writer/outline 的 prompt 骨架**。
**完整愿景**:三库全建+trope 分析层、版本系统+fingerprint diff 可视化、旋钮 UI+预设市场、outline 用 trope 库当积木、类型混血(多 genre_id 加权)、作者调味叠加、闭环评测(用 fingerprint 对账"生成稿 vs 类型质心",**注意按 reframe 是"像不像这一类"不是"像不像某作者"**)。

## 8. 更好的策略候选(挑出最有价值的几条 + 为什么)

1. **把 `fused_*` 提级为 `genre_template` 一等资产(MVP 的核心)。** 为什么:它已经是类型基因胚胎,改动成本最低、收益最直接,且一次到位地把"杂糅多作者"和"贴某作者"统一成同一台机器的两个挡位。是所有其他想法的地基。

2. **负面清单 / 反类型模板(negative template)当一等武器。** 为什么:用户扔掉相似度后留下的真空最该用它补。做类型模板时,"什么绝不能写"比"什么要写"更能定调、更省 token、更防 AI 腔(克苏鲁不解释怪物、不 HE、不用网络梗)。借自扩散模型 negative prompt,落地极便宜(craft 加一类 `anti_pattern`),收益最大。

3. **去签名化作为 L2→L1 的核心算子,用"方差当判别器"(剥离招 3)。** 为什么:这是最优雅、最可自动化的剥离——跨书低方差维=类型基因(固定),高方差维=作者基因(留旋钮)。直接复用已有 fingerprint_vector,无需新模型,且天然产出"哪些该固定、哪些该做旋钮"的答案。

4. **分轨混音(Solo/EQ/配额)而非加权平均。** 为什么:直击"杂糅会丢辨识度"这一最大盲点。辨识度来自"某轴极端+其他轴克制",处处中庸即谋杀。配额制 + 同槽互斥是防串味的最便宜护栏。

5. **两根正交滑杆(风格强度 × 自由发挥度)+ 四象限选择器。** 为什么:精准命中 reframe 1"看起来像、能自由发挥就够"。把"自由"做成一等公民而非 bug,且用户只需点一个象限,背后参数化拼装 prompt——降门槛与可控性兼得。

6. **盲测 A-B + 真原文暗桩,替代相似度当北极星评测。** 为什么:它测的正是 reframe 要的"像不像这一类/像不像人",且天然抗刷分(挑不出生成段才赢),又不需要昂贵裁判。配合"50 张命题回归集"当意象引擎单元测试,形成可回归的质量曲线。

7. **trope 库当 outline 的积木(打通文风层→剧情层)。** 为什么:这是单纯文风模板抓不到的"故事级类型基因",也是用户点名要的"桥段/套路"。让类型化转移矩阵+trope 库当"剧情骨架自动机",是把模板从字句层撬到结构层的最大杠杆。

## 9. 待验证 backlog(后续单独做,每条:假设→怎么验)

1. **去签名化阈值有效性**。假设:`universality≥0.5` 进骨架能正确区分类型/作者基因。怎么验:用招 4 留一交叉验证——3-5 本克苏鲁书建模板,看能否解释留出的第 N 本;同时跑招 8 看是否误把显眼私货收进骨架。

2. **"方差当判别器"是否成立**。假设:跨书低方差指纹维=类型基因。怎么验:算多本同类书的 fingerprint 质心+各维方差,人工核对低方差维是否确为"克苏鲁书都这样"、高方差维是否确为"某作者私货"。

3. **融合会不会变粥**。假设:分轨+配额+条件分流能避免平均化。怎么验:用配方 A 生成若干段,做盲测——读者读到的是"一个新自洽腔调"(赢)还是"能逐一辨认 A/B/C 的拼贴"(串味)或"谁都不像的平均"(变粥)。

4. **agentic + 跨书语料池是否真比单书检索好**。假设:模型从所有同类源书自取范例,质量优于限单书。怎么验:同一章 outline,A 组限单书检索、B 组跨书 agentic,盲评成稿的类型味与画面感。

5. **负面清单的防 AI 腔/防穿帮收益**。假设:`anti_pattern` 进 prompt 禁止清单能显著降低语域穿帮和 AI 腔。怎么验:同模板开/关负面清单各跑 100 段,统计语域穿帮率(现代词黑名单命中)、AI 腔特征命中率。

6. **意象库"新鲜度×说得通"能否量化且不反噬**。假设:`新鲜度=没见过×还说得通` 可近似度量且不会逼模型写怪话。怎么验:跑一批,人工标注"新鲜且通顺/新鲜但不通/陈词",看指标排序与人工是否一致;观察优化该指标后是否出现"为新鲜写怪话"。

7. **旋钮是否真"可预测、可微调"**。假设:拖一线旋钮→成稿对应维度单调变化。怎么验:固定 outline+seed,只动单个旋钮(如修辞浓度 20/50/80),看成稿对应维度是否单调可感、其他维度是否稳定(无串扰)。

8. **风格 Linter / 判别器作质量门是否可靠**。假设:轻量判别器能分开不同类型版本、模板自洽度能抓质量滑坡。怎么验:用同 outline 出克苏鲁/武侠两版喂判别器看准确率;人工标若干"塌方段",看 Linter 是否命中。

9. **章节类型→预设自动路由的命中率**。假设:按章类型自动套预设,用户多数不否决。怎么验:对一批章 outline 跑自动路由,统计人工否决率,看是否低到"几条规则+偶尔干预"可用。

10. **"贴原作者"用区间命中而非越像越好是否更优**。假设:落原作者风格区间即满分、越像反而变复读。怎么验(C 场景):分别用"越像越好"和"区间命中"两套目标生成续写,盲测哪套既像原作者又不像复读机。

11. **类型混血(多 genre 加权)产物是否成立**。假设:`_union/_avg` 思路做模板间融合能产出可用的杂交类型。怎么验:孵化"种田文×宇宙恐怖",试写片段,人评可行性与辨识度。

12. **共性提纯是否会抽出"最 cliché 的部分"(盲点 1)**。假设:取最大公约数可能=取最套路部分,反而更像 AI。怎么验:对比"纯共性模板"与"共性底色+强制个性留白槽"两版成稿的套路率与追读欲。

13. **子卡级增量版本是否真省成本**。假设:改 trope 不必重抽 atmosphere。怎么验:实现子卡独立 updated_at/source_slugs,跑一次只改单子卡的重建,核对其余子卡未被触发重算、成本下降。

## 补充与盲点(完整性批判)

> 由独立"完整性批判" agent 对上文逐条挑刺,直接并入。下列为正文之外的增量。

**漏掉的重要场景/策略**
- 缺"反向场景":用户已有半成品/烂尾稿,要的不是续写而是诊断+止损(找出哪里塌方、能不能救、救的成本)。这是比从零起盘更高频的真实入口。
- 缺"风格漂移是用户想要的"这一挡:连载中主角黑化、文风随剧情由轻松转沉重,此时"防漂移护栏"反而是 bug。护栏需要一个"计划内漂移路标"豁免机制。
- 缺多语言/翻译腔场景:中译外、外译中续写、网文出海,类型模板里的"语感"部件跨语言不可移植,需单列。
- 缺成本/延迟作为一等约束:9 部件、三层数据、agentic 跨书检索都默认算力无限。应有"轻量挡"(只用 L1+负面清单,不跑检索)与"全量挡"的明确分界和触发条件。
- 缺版权/合规场景:贴原作者挡位、跨书检索语料的来源合法性、洗稿风险边界,文档完全回避。
- 缺人类作者协作闭环:模板是给 AI 用还是给人看?若给人,需要"可读的写作指南"导出形态,而非只有机器可消费的 JSON。

**过度乐观/没说清**
- "去指纹+统一虚拟叙述者"假设杂糅后能收敛出一致声音,但更可能产出"谁都不像的平庸声音"——第 9 节虽列了"共性=最 cliché 部分"风险,正文却仍把统一叙述者当解法推,自相矛盾。
- "最大公约数+辨识度"未说清两者权重谁优先、冲突时怎么办——辨识度往往恰恰来自非公约数的部分,这对张力没有被正视。
- "trope 库当 outline 积木"乐观假设 trope 可自由拼装,但 trope 之间有强依赖/互斥(如"废柴流"与"开局无敌"互斥),缺依赖图就会拼出逻辑矛盾的大纲。
- 三层数据模型(L1/L2/L3)未说清归属冲突:某手法到底算类型共性还是作者签名,边界模糊时入哪层、谁裁决,没有规则。
- "盲测暗桩"作为评测尺子,没说谁来做盲测、样本量、成本——人评不可规模化,这把尺子可能比相似度更不可落地。

**用户 reframe 里被忽视的点**
- "做菜法"隐含可教学/可复现给人,但文档落点全在数据资产与 DB 表,丢了"配方应当是人能照着做的"这一层。
- "贴原作者退化为可选挡位"被采纳,但没补"为什么仍要保留它、何时该升回主挡"(粉丝向同人、指定作者代笔仍是刚需)。
- reframe 说"杂糅是常态",却没回答常态下的默认行为应是什么——文档默认仍偏单作者管线,杂糅当特例处理。

**矛盾/回避取舍**
- "方差当判别器去签名"与"要辨识度"直接对冲:去掉高方差特征=去掉最具辨识度的部分,文档把两者并列为优势策略却不点破其互斥。
- MVP vs 完整愿景未给砍线:13 项 backlog、7 条新策略哪些进 MVP、哪些缓,没有优先级和依赖排序,等于没有路线图。
- "何时不量化"与"分场景成功标准表"并存,但没界定二者的适用边界——哪些场景表里给了指标却又属于"不该量化",存在重叠灰区。
- 元数据"3 贯穿"与"9 部件"的关系未说清是正交还是嵌套,落到表设计时会产生字段归属歧义。

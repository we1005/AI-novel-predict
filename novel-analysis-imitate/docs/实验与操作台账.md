## 2026-06-28 · agentic style-search:是否过度设计(三轮消融 + 重合度 + 公平复赛)

专题详档:[`agentic-search-消融结论.md`](agentic-search-消融结论.md)。脚本:[`experiments/`](experiments/)。

### ① 检索基座 + 自我污染修复
- 动机:用户提出"写作时 LLM 调 search tool 检索素材库"。先建可对比地基,不直接重构。
- 操作:新增 `backend/app/craft/search.py`(`search_corpus` 章节正文 BM25 + `search_snippets` 笔法库);
  修 FTS5 trigram 必须 ≥3 字(2 字概念词零召回)→ 滑动 3-gram + OR。`draft` 风味召回排除已生成章(防自污染)。
- 结果:对余烬之铳验证每主题 3 条相关命中;回归 8/8。
- 落地:`f99965e`(基座+脚手架)、`a423010`(自我污染)。

### ② 三组消融 v1(无参考 / push / agentic)
- 操作:`backend/.venv/bin/python novel-analysis-imitate/docs/experiments/ablation_search.py`
- 结果(余烬之铳,4主题×2样本):fidelity A/B/C = 32.0/30.5/31.6(分不开);**盲评 = 37.9 / 66.7 / 45**。
- 结论:push 检索参考把盲评 +29(有用,但只在 holistic 盲评显现);agentic(45)反不如 push(此结论后被 ② 的 bug 推翻)。
- 落地:`df834b2`(结论 + `ablation_search_results.json`)。

### ③ 重合度校验(push 高分是真迁移还是照抄?)
- 操作:`...ablation_overlap.py`(LCS + ≥8字片段覆盖率,plain 作偶然基线)
- 结果:push 平均 LCS 6.1 / 覆盖 1.2%;plain 2.9 / 0%。
- 结论:**push 高分不是照抄,是真风格迁移**(最严重一例抄 18 字,整体可忽略)。保留:本轮注入为短 FTS 片段。
- 落地:`dc84292`(+ `ablation_overlap_results.json` 含样本产出)。

### ④ craft 笔法库填库
- 动机:圆"按景物/建筑标签检索"的设想——之前 craft_snippet 三书皆空。
- 操作:`pipeline.extract_all(batch_size=5, max_chapters=120, slug="余烬之铳")`
- 结果:**439 片段 / 26 类 / 26 风格卡**(scene_env 28、scene_place 12、object 14、combat 35…);库在 gitignored novel.db。
- 结论:`search_snippets(category="scene_place")` 即"按建筑景物检索",数据就绪。

### ⑤ agentic 公平复赛 v2(整段注入 + 自选类目 + 重合度)+ 自查 token bug
- 操作:`...ablation_search_v2.py`(注入 craft 整段 excerpt;C agentic 自选类目+查询)
- **闭环自查**:首跑 agentic 总退化成 `['scene_env']`+主题原句 → 单独验证规划步发现根因是规划调用
  `max_completion_tokens=400` 截断 mimo → JSON 解析失败 → 退化默认值(同 E5/基因组 token 坑)。修到 1500 重跑。
- 结果(token 修复后):盲评 A/B/C = 46.7 / 50.6 / **50.0** → **agentic 与 push 打平**(非"输");重合度≈0(无抄袭);
  类目级检索 +4 远逊 v1 关键词级 +29。
- 结论:① 检索参考有用但**收益取决于精度**(关键词 >> 类目);② **agentic ≈ push**,多一次规划调用换同等质量 →
  **不做默认,留 opt-in**(多主题/跨书场景);③ 真正杠杆是检索精度,非 push/pull。
- 落地:`4be1b27`(v2脚手架)、`88de2e0`(修 token 截断)、`5c8e98a`(v2 结论 + 结果)。

### ⑤ agentic 公平复赛 v2(整段注入 + 自选类目 + 重合度)+ 自查 token bug
- 操作:`...ablation_search_v2.py`(注入 craft 整段 excerpt;C agentic 自选类目+查询)
- **闭环自查**:首跑 agentic 总退化成 `['scene_env']`+主题原句 → 单独验证规划步发现根因是规划调用
  `max_completion_tokens=400` 截断 mimo → JSON 解析失败 → 退化默认值(同 E5/基因组 token 坑)。修到 1500 重跑。
- 结果(token 修复后):盲评 A/B/C = 46.7 / 50.6 / **50.0** → **agentic 与 push 打平**(非"输");重合度≈0(无抄袭);

  **不做默认,留 opt-in**(多主题/跨书场景);③ 真正杠杆是检索精度,非 push/pull。
- 落地:`4be1b27`(v2脚手架)、`88de2e0`(修 token 截断)、`5c8e98a`(v2 结论 + 结果)。

## 2026-06-28 · 红蓝对抗 E 系列待修收尾(E8/E3/E6/E4)

接第三轮 E1–E8 汇总表,把剩余「待修/部分修」逐条做完。全部带确定性单测,回归从 11 → 16/16。

### E8 · EntityState 状态/diff 对账(gained∩lost)
- 病:同章既「获得」又「失去」某物时,state 与 diff_json 不自洽(双记/漏减)。
- 修:`extract.py` 加模块级纯函数 `reconcile_items(prev, gained, lost)` → 净出 gained∩lost,
  state 与 net_gained/items_lost 一致可逆;`_persist_states` 落归一化 `applied` diff + `_reconciled` 标记。
- 测:3 例(纯得 / 同章得失抵消 / 失已有)。落地见对应 commit。

### E3 · 重切章孤儿行 + schema 漂移
- 病:重切章后旧章号派生行变孤儿(指向已不存在/含义已变的章),静默累积 + 双计。
- 修:`split.py` 重建 chapters/FTS 后,按「chapter > 新max」原始 SQL 清理 11 张派生表孤儿
  (try/except 逐表,缺表跳过)+ 伏笔回收点越界置 NULL;返回 `orphans_pruned`。
- 注:完整 Alembic 迁移框架列为更大专项,暂缓。

### E6 · 429 成本放大 + 跨 provider 故障切换(默认关闭)
- 病:`@retry` 限流重试 7×(15–120s)→ 成本放大 + 单 provider 宕机整链 hang ~14min,无降级。
- 修:`settings` 加 `get_fallback_model()`(读 settings.json `fallback_model`,默认空=不启用);
  `call` 拆 `_call_impl`(@retry 原体)+ `call` wrapper:主模型失败后若配了 fallback(应属另一 provider)
  降级再试一次,否则原样 re-raise;`_adaptive_stop` 配降级时限流只重试 2 次快速短路。
- 默认零行为变化(未配 fallback 完全等同历史)。测:2 例(未配 re-raise / 配了降级)。落地 `(本次)`。
- 残留:未配 fallback 时 ×7 重试为限流固有(已文档);要用降级须在 settings.json 配另一 provider 模型 + 填其 key。

### E4 · 仿真每轮活状态 + 产物回灌(此前仅修了 profile 边界 >=200)
- 病1 每轮快照:`initial_state` 全程冻结,每轮 `my_current_state` 同一份 → 角色拿不到自身上轮结构化状态。
- 修1:维护 `live_state`,每轮 `_fold_round_into_state` 折入各角色 `events_during_sim` 轨迹,下一轮带演进;
  `round_record` 增 `state_snapshot`(模型注释早预留)。
- 病2 回灌:`final_text` 从不落 ChapterDraft,`SimulationRun.chapter_draft_id` 有列never写,docstring 第6步是空话。
- 修2:落 `status="draft"` 的 ChapterDraft 并回填 `chapter_draft_id`,使产物进*既有的、有人审 gate* 的复审/回灌链
  (草稿被接受才 `extract_one_chapter` 回灌 canonical EntityState)。
- **关键设计判断**:**刻意不**在仿真里静默回灌 canonical EntityState——仿真是假设性的,
  直接写回真值会用推测内容污染记忆,比原 bug 更糟;正确通路是 draft → 人审 → 接受。
- 测:3 例(轨迹累积 / 非dict slot 稳健 / 标题抽取)。回归 16/16。落地 `(本次)`。

# V_genre · 通用类型模板能否产出"够克味"的文字 —— 结论(方向正题)

从 5 本**不同作者同题材**(克苏鲁+维多利亚:诡秘之主/余烬之铳/诡秘地海/黎明医生/深海余烬)的**语义层**抽一个通用类型模板,
验它能否产出够题材味、且不套路的文字。整合 V1(题材在语义层)、V2(纯共性更套路→带求异留白)。
脚本:`docs/experiments/v_genre_template.py`。3 臂 × 3 主题盲评。

- **A 类型模板** = 5 书语义共性模板(意象池/母题/世界观语汇/氛围/味道要诀)+ 求异指令 —— 我们系统的产物
- **B 朴素 prompt** = 裸"用克苏鲁+维多利亚风格写" —— 没我们系统时用户默认能拿到的
- **C 单作者** = 仅贴诡秘之主风格 —— "贴一个名作者" vs "通用模板"

## 数据(3 主题均值;套路越低越好)

| 臂 | 克味 | 套路 | 新鲜 | 最克味次数 | 最不套路次数 | 陈词命中 |
|---|---|---|---|---|---|---|
| **A 类型模板** | **88.3** | 51.7 | **81.7** | **2** | 1 | 0 |
| B 朴素 prompt | 85.0 | 63.3 | 66.7 | 0 | 0 | 0 |
| C 单作者(诡秘之主) | 86.7 | **46.7** | 76.7 | 1 | 2 | 0 |

## 结论(方向成立)

1. **A 比 B(裸 prompt)三轴全胜**:克味 88.3>85、套路 51.7<63.3(↓12)、新鲜 81.7>66.7(↑15)。
   → **抽取的模板有真实增量,不是靠 LLM 自带常识**。这正面回答了最初"是否过度设计"的质疑:**比直接叫 LLM 写该题材明显更好**。
   增量主要落在**去套路 + 更新鲜**(克味本就因 LLM 题材先验而都不低),恰是 V2 留白机制的功劳。

2. **A ≥ C(贴单作者)**:克味、新鲜都更高(单作者仅"去套路"略好,2/3 最不套路)。
   → **印证用户判断:不必非得贴某个名作者,通用语义模板就够好、甚至更克味更新鲜。** "贴原作者"退为 niche 成立。

3. **题材可从多作者语义层抽出可用模板**(呼应 V1:题材在语义层)。抽出的模板本身质量高(见下),已是可交付的"克苏鲁维多利亚写作配方"。

## 抽出的类型模板(可交付样例)

> 核心意象池:蒸汽机械、煤气灯、雾都、古神低语、禁忌知识、异变肢体、幽灵船、面具舞会、秘密结社、异常收容物。
> 母题:新人被引入隐秘组织;接触禁忌知识致精神污染;表面秩序下的疯狂真相;以"调查/探索"为名的危险旅程;理智与疯狂边界试探。
> 世界观语汇:非凡者/超凡者、收容物/异常、教会审判机关、下城区/黑市、探索者协会、诅咒人偶、神之低语、危险等级。
> 氛围:压抑疏离、知识即诅咒、个体在庞大未知前的渺小、文明与野蛮的撕裂。
> 味道要诀:用蒸汽朋克的"可理解外壳"包裹不可名状的"内核";恐惧源于认知;"在煤气灯下研究深渊"的冰冷考究口吻。

## 诚实边界

- n=3 主题、单裁判;裁判自带强题材先验(故 B 裸 prompt 克味也有 85)→ A 的克味增量(+3)不大,真正增量在**套路/新鲜**两轴。要硬数字需 ≥10 主题多轮 + 多裁判。
- 模板是"语义共性",未含作者结构指纹(按 V1 定论,题材本就不该含结构层)。
- 未验:跨题材模板(克苏鲁×种田)、模板的旋钮可控性(后续 V6/#7)、模板在长篇连写中的稳定性。

## 整轮验证(V1→V_genre)对方向的总判
- 题材在语义层,结构指纹=作者层(V1);裸取共性会套路、需强制求异(V2);多源融合不变粥、防"缝"即可(V3);
  **通用语义模板 > 裸 prompt、≥ 贴单作者(V_genre)**。
- → **用户的 reframe 成立且系统有真实增量**:做"可复用、可杂糅、带求异/消缝护栏的语义类型模板"是对的方向;
  "贴原作者"用结构指纹、退为 niche。

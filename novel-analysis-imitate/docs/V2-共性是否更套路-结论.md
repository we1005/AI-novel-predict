# V2(backlog #12)· 共性提纯会不会更套路 —— 结论

存亡问题:取"最大公约数"做类型模板,会不会反而更陈词滥调(共性=最套路部分)?
3 臂 live 对照(克苏鲁蒸汽朋克:余烬之铳+深海余烬),3 主题各出 A/B/C 三段,盲排 + 确定性陈词计数。
脚本:`docs/experiments/v2_common_vs_cliche.py`。

- **A 纯共性模板**(两书最大公约数风格)
- **B 单书风格**(仅余烬之铳,个性参照)
- **C 共性 + 强制个性留白槽**(共性底色 + "大胆加入独特意象/转折、避免陈词")

## 数据(3 主题盲评,映射回真实臂)

| 指标 | A 纯共性 | B 单书 | C 共性+留白 |
|---|---|---|---|
| 最**不**套路次数 | 0 | 0 | **3** |
| 最套路次数 | **2** | 1 | 0 |
| 最追读次数 | 1 | 1 | 1 |
| 确定性陈词命中合计 | 1 | 0 | 0 |

裁决理由摘录:A「堆砌蒸汽朋克符号且对话生硬」「整体组合和细节处理显陈旧」;C「意象最新颖独特,但叙事节奏较慢」(两次提到 C 节奏偏慢)。

## 结论

1. **假设成立(方向确认):裸取最大公约数确实更套路。** A 纯共性 2/3 被判最套路、0 次最不套路 → "共性=最 cliché 部分"这个 brainstorm 盲点是真的。**不能把"最大公约数"直接当模板用。**

2. **留白槽是有效解药。** C(共性+强制个性留白)3/3 最不套路、0 次最套路 → 在共性底色上**强制注入新鲜/个性**能把套路压下去,同时保留题材味。**架构含义:类型模板必须内建"强制新鲜/个性留白"机制(负面清单 + 主动求异指令),而非只存共性特征。**

3. **关键 nuance:"不套路" ≠ "追读"。** 追读欲 A/B/C = 1:1:1 打平;A 虽套路却拿过一次"最追读"(情节/悬念直接)。且 C 两次被评"节奏较慢"。→ **新鲜度与节奏/追读是正交轴,会 trade-off**:留白买新鲜可能折损节奏。模板需要新鲜 + 节奏**双护栏**,不能只优化"去套路"。

4. **副发现:确定性陈词黑名单太小(0/0/1),判别力近无。** 若要"廉价陈词度量",黑名单需大幅扩充,否则只能靠 LLM 盲评。

## 诚实边界

- n=3 主题、单轮、单裁决;方向性而非定论。要硬数字需 ≥10 主题多轮。
- B 单书可能也含余烬作者套路;"个性参照"不完美。
- C 的"节奏变慢"可能是"求异指令"让模型多写描写、少推进——可在指令里加"保持推进"约束再验。

## 对后续的影响

- **模板设计(直接落点)**:`genre_template` 必须含 ① 共性底色 ② 负面清单(anti-pattern,接 V4 验证)③ "强制求异/留白槽"开关。**纯共性不可裸用。**
- **评估(呼应 brainstorm 第6节)**:套路度、新鲜度、追读/节奏要**分开测**(它们正交);别用单一"好不好"。
- **V3(融合变粥)**:V2 已侧证"共性会平庸化";V3 进一步看"多作者融合"是否=更高级的共性平均化,以及分轨/配额能否救。

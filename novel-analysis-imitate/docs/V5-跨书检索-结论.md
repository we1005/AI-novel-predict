# V5(backlog #4)· 跨书 agentic 检索 vs 单书 —— 结论(反直觉)

问:写作时让检索从"所有同题材源书"自取范例,是否比限单书更出活?隔离变量:同一类型模板底色 + 同一组中文规划查询,只差检索范围。
脚本:`docs/experiments/v5_crossbook_retrieval.py`。5 本克苏鲁池 vs 单书(余烬之铳),3 主题盲评。

## 数据(3 主题均值)

| 臂 | 克味 | 意象丰富 | 质量 | 更好次数 |
|---|---|---|---|---|
| 单书(余烬之铳) | **92.3** | **89.0** | **90.7** | **3** |
| 跨书(5 本池) | 81.7 | 82.7 | 85.0 | 0 |

注:单书在主题2/3 检索 **0 命中**(只剩类型模板底色),跨书有 4/1 命中——**单书无片段时仍完胜跨书有片段**。

## 结论(推翻 #4 假设)

1. **跨书 agentic 原文检索注入,反而更差(0/3 胜)。** 写作时混入 5 个**不同作者**的异质原文片段 → 风格/意象信号互相打架、稀释克味(正是 V3"缝感/拼贴"在检索层的翻版)。
2. **真正起作用的是"预蒸的类型模板",不是"写时多书生检索"。** 单书 0 命中时只靠 V_genre 模板底色就赢——说明跨书知识应**预先蒸成一个连贯模板(V_genre 那条路)**,而非生成时 raw 注入多作者片段。
3. → **架构定调:多书 → 先离线蒸成连贯 genre_template(去异质);写作时检索若要用,优先单一来源(同一作者/同一本)保证范例同质。** 这反而**强化**了 genre_template 产品功能的必要性。

## 诚实边界

- 混淆:单书在 2/3 主题 0 命中,使"单书"实际≈"模板 only"。所以更精确的结论是:**"跨书 raw 片段注入" < "纯模板(或同质少量片段)"**。"单书 vs 跨书"的纯净对比因 0 命中被弱化。
- n=3、单裁判。中文规划查询修复后才有效(英文查询是初版 bug,已修)。
- 未测:若跨书检索**先按风格归一/改写**再注入(消异质),是否能扳回——这才是"跨书池"可能的正确用法,列 backlog。

## 对产品的影响
- **不做**"写作时跨多书 raw 检索注入"(默认有害)。
- **做** genre_template:把多书知识离线蒸成连贯模板(本次正在落地)。
- 写时检索(#78 push / #79 agentic)继续限**单一来源**同质片段。

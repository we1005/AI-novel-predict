# V1(backlog #2)· 方差当判别器 —— 结论

确定性实验(不烧 token):对 6 本书算生产指纹的 8 个确定性维,按簇算"簇间方差/簇内方差"比(类 ANOVA F)。
簇:**江南**(同作者跨子类型:九州/天之炽/龙族)、**余烬**(同题材克苏鲁蒸汽朋克:余烬之铳/深海余烬)、**网文对照**(末法王座)。
脚本:`docs/experiments/v1_fingerprint_variance.py`(可复跑)。

## 关键数据

各维判别力 F(簇间/簇内方差,高=能判别簇):

| 维 | F | 判定 |
|---|---|---|
| **hedge_per_kchar(模糊限制语:似乎/仿佛/不可名状)** | **28.6** | ★强判别 |
| dialogue_ratio(对白占比) | 4.8 | 中 |
| comma_per_kchar | 1.4 | 弱(且退化,见下) |
| avg_sent_len / para_len / ellipsis / sent_len_cv / reduplication | <1.0 | 弱/噪声 |

- 余烬簇 hedge = 2.2 / 2.07,江南 = 1.27/1.12/1.05,网文 = 1.25 → **克苏鲁簇的"模糊限制语"密度几乎翻倍**,极合直觉(不可名状/仿佛/似乎是该题材的招牌腔)。
- 江南簇 `sent_len_cv` = 0.68/0.69/**0.70**(跨三个差异极大的子类型几乎不变)→ 强作者签名候选。

## 结论(对假设的修正)

1. **"方差能当判别器"——部分成立,但 brainstorm 里的表述要修正。** 原假设"跨书**低方差**维=类型基因"是**错的**:很多维(sent_len_cv 在所有书都 ≈0.68–0.80)是**低方差但属语言通性**,不是基因。正确判据是 **between/within 的 F 比**(簇内稳 + 簇间分得开),而非"原始低方差"。8 维里只有 **hedge(F=28)强、dialogue_ratio(F=4.8)中**通过,其余是通性噪声。

2. **当前生产指纹太"薄",撑不起类型身份。** 8 个确定性结构维里,真正能把克苏鲁簇分出来的基本只有 hedge 一维。**题材的灵魂(意象/母题/修辞/语域)不在这些结构维里**——它在 LLM 抽取的基因组层(词汇/修辞/氛围)。→ **架构启示:类型模板不能只靠结构指纹定义,必须以语义层(意象库/修辞目录)为主、结构指纹为辅。**

3. **发现一个生产 bug:`comma_per_kchar` 维退化。** 它只数半角逗号+顿号,中文多用全角逗号 → 末法王座该维=0.000、余烬之铳=0.13,基本失效。应修为同时数全角",",否则这维白占。

4. **作者基因确有其物(可廉价识别)。** 江南 3 部跨子类型,`sent_len_cv≈0.68`、`avg_sent_len`、`para_len`、`hedge`、`redup` 都低 CV → 这些是"江南不管写什么都这样"的签名。说明"作者基因 vs 类型基因"分层是有现实依据的。

## 诚实边界

- 簇有**作者混淆**:江南簇=同作者(测到的是**作者**基因);余烬簇可能同作者。要干净分离"类型基因 vs 作者基因",需要**同题材不同作者 3+ 本**的语料(用户后续补)。hedge 把余烬分出来,可能是克苏鲁题材性、也可能是余烬作者性——本实验无法区分。
- 只有 8 个确定性维;真正的类型判别力应在语义层补充验证(V2 会触到)。

## 对后续的影响

- **V1 → 下游**:判别器/质量门(#8)若用,应基于 **F 高的维**(hedge、dialogue_ratio)而非全维等权;raw-low-variance 不可直接当"基因"。
- **修生产指纹**:comma 全角 bug 值得顺手修(小);可考虑给指纹加更多"题材性"确定性维(如意象词命中密度),但更可能直接上语义层。
- **类型模板设计**:语义层(意象/修辞/母题)是主,结构指纹是辅、只留 F 高的几维。

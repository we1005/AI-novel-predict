# genre_template 抽样代表性 · 头脑风暴 + 方案(含评审)

> 触发:用户担心"全书均匀取 K 段可能碰巧全落对白/景物/打斗,导致样本写作模式分布不均"。
> 用 7 棱镜 workflow 发散 + 评审。已把每本上限调到 ~20k 字、K=12 段(合计 ~10 万字)。

## 结论先行(最有价值的定性)
**分布不均主要伤"句法层(syntactic_patterns/cliche_sentence_templates)+ atmosphere/flavor_recipe";基本不伤 imagery/motifs/worldview_lexicon/anti_patterns**(它们是全书离散词表,靠 5 本×12 段的覆盖广度就兜住——就算 12 段全是对白,克苏鲁的"不可名状/古神"照样反复出现)。
**而真伤的句法层,恰好已被降级为"分析-only / 生成后 linter"(inject_syntax=False),没进生成回路。→ 这个顾虑的实际杀伤力比直觉小一个量级。** 故方案偏"轻"。

## 策略光谱(成本↑)
- **S0 过量+蒸馏指令**:段数 12→16-20,`_distill` system 加"补全对白/动作/景物/心理各模式写法"。≈0 成本。
- **S1 更多更小段**:spread 12→18-24,每段 300-500 字,用统计学摊平偏斜。≈0 成本、零新代码。
- **S2 廉价确定性分层**:对候选段算 `dialogue_ratio` 粗分 3 桶(对白重/均衡/描写重),各桶保底取。纯正则。**最对症**(用户担忧就是"对白 vs 描写"这一轴)。
- **S3 嵌入/特征聚类**:60 个样本点做 KMeans → 统计意义约等于零,**砍掉**。
- **S4 LLM 轻量打标**:每段 lite 模型判 scene_type,分层。中成本。
- **S5 复用 beat scene_type**:`sample_by_scene` 现成,但要先全量 beat(贵)。**只为 genre_template 单跑 beat = 过度设计**(且 scene_type=叙事功能,与"写作模式"错位)。

## map-reduce 蒸馏(解大输入,顺带缓解单本偏斜)
- 每本单独蒸 mini-template → 合并。绕开上下文墙 + 单本注意力不被挤。
- **评审关键修正:合并有损**——词表类(imagery/motifs/lexicon)并集安全;**单值类(atmosphere/flavor_recipe)不能并集**,否则截断取一或再概括→味道被抹平变钝。这两个字段要"看 5 本原始片段浓缩再写一次"。
- **条件式触发**:`if 总样本 token > 上下文70% then mapreduce else single`;无脑默认 mapreduce 对小样本性价比倒挂。

## 推荐落地顺序(评审总纲,贯彻"先测再建")
1. **先读代码确认 min/max_chars 作用域**(单本 vs 总量)+ 实际输入 token 量。→ 已确认:**单本**上限,5 本合计 ~10 万字符。
2. **零成本诊断(必须前置)**:打印各书**全书** `dialogue_ratio` 直方图。**顺带验正则对克苏鲁译本是否失效**——中文对白有 `""`/`「」`/`『』`/破折号 多种形态,`structural_features` 只认 `""`,若某本贴近 0 说明识别失效,分层比不分层更坏。
3. **若偏斜不严重(§1 判断大概率如此)→ 只上 S1(spread↑)+ S0 指令,收工。** 这是"一行 config + 一句 prompt"的全局最优,连 map-reduce 都未必要写。
4. **若确超上下文 → 加条件式 map-reduce**,合并按字段类型分治(词表并集、味道重蒸)。
5. **stratify=dialogue3 只在诊断证明严重偏斜 且 质量评测证明它拉高 fidelity 时才写**,且带 `spread>=9` 门槛、余数段补给"最接近全书均值"的桶。fingerprint 聚类不做。

## 用户原想法:砍/留
- **留**:问题意识对(尤其对句法层);"分层抽样"结构对(S2 是其廉价实现)。
- **砍(过度设计)**:① 按 8 类 scene_type 精细分区——用户担忧是"对白 vs 描写"(写作模式),不是"铺垫 vs 高潮"(叙事功能),`dialogue_ratio` 一维就抓住,不必跑贵 beat;② "工作量太大"是误判(S2 近乎零工;是被"要走 beat"那条重路吓住);③ **在诊断证明偏斜严重前,别写任何分层**。

## 验证(若真做分层)
- A 客观(零 LLM):各策略样本的 `dialogue_ratio` 组内方差/极差 + **样本均值 vs 全书真值的偏差**(代表性硬指标)。
- B 质量(接 V_genre/V2):各策略模板 → preview → 三轴盲评 + `fingerprint.compare` fidelity。**若 A 更均衡但 B 无变化 → 证实语义部件鲁棒、分层是安慰剂,回退。**

## 诊断结果 + 落地(2026-07-01)
零成本诊断(`docs/experiments/genre_sample_skew_diag.py`):5 本全用曲引号 `""`,`dialogue_ratio` 正则**有效**;
各书全书对白比 **0.19–0.32**(健康、非退化)。→ 每本对白仅约 1/4,12–16 段均匀取**天然混各模式**,偏斜不严重。
STRONG lane = **mimo-v2.5-pro(1M 上下文)**,10 万字符单次蒸馏**吃得下、不截断** → **map-reduce 条件不触发,不做**。

**落地(数据驱动、最省)**:只上 **S1 段数 12→16** + **S0 蒸馏跨模式指令**(_distill system 加"样本可能偏重某类场景,请跨对白/动作/景物/心理各模式分别提炼")。
**不做**:场景分层(偏斜不严重 + 语义部件本就鲁棒)、map-reduce(上下文 1M 够)、fingerprint 聚类(60 点无统计意义)。
若将来换小上下文 STRONG 或诊断显示某书偏斜严重,再按本文档决策树上条件式 map-reduce / dialogue3 分层(带 spread≥9 门槛)。

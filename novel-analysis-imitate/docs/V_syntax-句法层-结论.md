# V_syntax · 句法/句式层 —— 结论(诚实:抽取赢、生成注入未验出增量)

针对用户批评("文风也是语法/句法/句式;要抽题材惯用句式 + 套路句式 slot 模板")建句法层 MVP,
并按"代码-测试-验证一条龙"实测。两轮 live A/B(克苏鲁维多利亚模板,n=3 主题,单裁判)。

## 抽取侧:成功 ✅

`genre_template` 现能从 5 本同题材书抽出句法层(实测):
- **syntactic_patterns(题材惯用句式/翻译腔)** 5 条:状语前置、长定语堆叠、西式连接词(如此…以至于),**带原著例句**。
- **cliche_sentence_templates(套路句式 slot 模板)** 16 条:如「<人物>心头顿时掀起了惊涛骇浪(变体:心中一震/心头一紧)」「<反派>冷笑一声」——**句式+词序+槽位**,正是用户要"抽离出来"的东西。

前端 genre 详情页已展示这两层。**这直接兑现了用户"抽离出来"的核心诉求。**

## 生成侧:两条路都没验出增量 ⚠️(诚实负面)

**V_syntax(in-prompt 注入)—— 反而更差。** 同模板同旋钮,只差是否把句法层塞进生成提示:

| | 克味 | 套路(低好) | 新鲜 | 胜 |
|---|---|---|---|---|
| A 无句法 | 88.3 | **40.0** | 81.7 | **3** |
| B 含句法注入 | 83.3 | **65.0** | 63.3 | 0 |

→ 注入后套路**反升**、新鲜降。根因:**套路句式逐条列入提示=反向 priming**("别想粉色大象"——点名"心头掀起惊涛骇浪"反诱发);题材句式正向推使 prose 变重。

**V_syntax2(生成后 linter)—— 无可测收益。** 同一干净底稿 → 对命中套路句的句子定向改写,盲评原稿 vs 去套路稿:

| | 克味 | 套路 | 新鲜 |
|---|---|---|---|
| 原稿 | 85.0 | 70.0 | 63.3 |
| 去套路(linter) | 85.0 | 70.0 | 63.3 |

→ 3 主题**评分完全相同**(即便 linter 改了 238/377 字),套路分纹丝不动。"更好"1:2 但数值无差。

## 诚实结论

1. **句法层"抽取/分析"有价值且已交付**(用户诉求"抽离出来"达成);**但"用它改善生成"在 n=3 实测里未验出增量**:in-prompt 有害、linter 中性。
2. **决策(已落地)**:句法注入**默认关**(inject_syntax=False),恢复 V_genre 验证的好行为;抽取/展示保留。不把未验证的东西设为默认。
3. **确定性 detector 当前钝**:通用锚词("瞳孔收缩")跟这题材真实套路("心头惊涛骇浪")对不上,命中恒 0 → 要用必须**从该模板的 cliche_sentence_templates 现编译锚词**,而非通用表(未做)。

## 方法论局限(可能低估了真实效果)
- **裁判太钝**:单 LLM 打 0-100 套路分,对句子级改写给出**完全相同**的分 → 可能是裁判分辨率不足,而非真的无差。n=3 也太小。
- 不能据此断言"句法层对生成无用",只能说**这套度量没测出增量**。

## 下一步候选(未做,待定)
- A 接受"抽取/分析-only"(当前状态):句法层作为**让用户看懂题材句法 + 人工参考**的分析产物,不进生成。性价比最高、已可用。
- B 换更灵敏的评测:套路用"逐句二选一(哪句更套路)"强制选择 + 多裁判 + n≥10,重测 linter 是否真有微增量。
- C detector 从模板现编译锚词 → 做"硬性套路率"客观尺子,绕开钝裁判。
- 我倾向 A(默认)+ 必要时 C;B 成本高、收益不确定。

# 评测可信度:65.25 有几分真?谁来当裁判?(实测)

> 红蓝对抗第一轮把"评测"列为最大软肋(尺子循环 C1 / 覆盖太薄 C5 / 小样本 C2 / 无人类真值 C3)。
> 本文用**真实语料 + 真实模型**把这些质疑跑成数据,并据此改了代码、给出"谁当裁判"的诚实答案。

---

## 一、两个问题

1. **"基因组 65.25 vs 基线 56.75"这个数字可信吗?** 它来自一个中端 LLM 的 7 维盲评;客观对账那条线其实只用了 3 个正则维。
2. **仿写质量到底该由谁判?** 由我(更强的模型)终审,还是驱动别的模型判?

---

## 二、E1 · 尺子有效性(客观判别力)

**问题**:如果连"原作真文"和"别的书"都分不开,fidelity 这把尺子就没意义,65.25 更无从谈起。
**方法**(纯确定性,无 LLM):以 余烬之铳 真文为正样本、末法王座(网文)/天之炽/九州(江南)为负样本,
用 z-score 标准化 + 欧氏距离测"判别力 AUC"(0.5=瞎猜,1.0=完美)。

| 尺子 | 维度 | AUC |
|---|---|---|
| R_regex(当前主链) | hedge / reduplication | ~0.73 |
| R_indep(与基因组无关) | 句长 / 句长变异 / 段长 / 对白比 / 逗号密度 | ~0.77 |
| **R_all(两者合并 7 维)** | 上面全部 | **~0.91** |

**结论**:文风**确实可被量化区分**(0.91)——量化不是空中楼阁;但**当前 run_eval 只用 3 个正则维(0.73),把大部分信号浪费了**(实锤 C5)。

**已落地修复**(本轮):把"句长/句长变异/段长/对白比/逗号密度"这些**与基因组无关**的结构维加进
`_fingerprint.structural_features()`,接入 `fingerprint_from_text` / `compare` / `build_fingerprint`。
- 实测接入后:**同书 fidelity 92.6 vs 跨书(网文)44.0**,清晰拉开。
- 额外收益:这些维不来自基因组的 LLM 层,**部分破除了 C1 的"用自产 schema 量自己"循环**。

---

## 三、评委架构:现在怎么判、应该怎么判

### 现状(三条线,没有一条是"最强模型")

1. **LLM 盲评**:`genome_eval` 让路由到的 STRONG 模型(当前 `mimo-v2.5-pro`,中端)按 7 维打分——65.25 出处。
2. **确定性指纹 fidelity**:`compare()`(本轮已增强),非 LLM、可复现、零偏置。
3. **三审一编辑 + 阶段人审 gate**:前者还是同一路由 LLM;后者是人(用户)。

### E2 · 评委可靠性实测(给评委一段原作真片段当参考,打"相似分")

| 候选 | `mimo-v2.5`(中端) | `mimo-v2.5-pro`(更强) |
|---|---|---|
| 原作真文(余烬之铳) | 84 | 80 |
| 网文(末法王座) | 50 | 40 |
| 江南腔(天之炽) | 52.5(单样本 [30,75]) | 30 |

三点发现:
- **两档都通过基本 sanity**:把原作真文判为最像(评委没坏)。
- **更强的裁判分得更开**:pro 把真文(80)与他书(30–40)拉开 ~45 分;中端真文(84)但他书都 ~50、网文≈江南**分不开**。→ **裁判能力直接决定结论**,支持"用当前可调用的最强模型当主观裁判"。
- **单次打分方差巨大**(江南腔中端 [30,75]):必须多次采样取均值 + 置信区间(C2)。

### 推荐:分层裁决,而不是"谁当唯一裁判"

升级到最强模型当裁判是对的,但**换个更强的 LLM 仍逃不出"无人类真值"(C3)**——LLM-as-judge 有 self-preference / 长度 / 位置偏置。所以:

1. **客观底线(非 LLM)**:确定性指纹 fidelity 先筛掉"明显不像"(E1 已把它提到 AUC 0.91、92.6/44 可分)。
2. **主观高判(最强可用模型)**:文风评委升级为当前最强模型,但配去偏控制——盲评、A/B 随机顺序、**多采样取均值±CI**、必要时"refute 模式"(让它找不像的证据而非直接打分)。
3. **真值锚(人)**:少量、定期的人工 spot-check(逐维 checklist + inter-rater kappa)校准前两层——这才是 ground truth,其余都是它的低成本代理。

> 一句话回答"谁当裁判":**我可以、也应当是最高那一档 LLM 裁判,但不该是唯一终审**。
> 最稳的是「确定性指纹兜底 + 最强模型主观评(带去偏)+ 人工抽检锚定」。

---

## 四、对 65.25 的诚实定性

- 它**不是假的**(评委能把真文判最像、基因组确有结构维优势),但它**目前撑不起强结论**:出自中端单评委、单稿、无 CI、且客观对账那条线太薄。
- 在用"最强评委 + 多采样 + 增强后的确定性指纹 + 少量人工锚"重测之前,**65.25 应视为"待复核"**。
- 本轮已把客观侧做硬(E1 修复),评委侧给出了升级方向与去偏清单——下一步是把 `genome_eval` 的评委路由到最强模型并加多采样/CI。

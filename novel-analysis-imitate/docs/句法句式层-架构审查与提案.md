# 文风架构 · 句法/句式层审查与提案

> 触发:用户指出"文风不只是词汇频率,还有格式/语法/句法/句式组合"。要能抽两类:
> (A) **题材惯用句式 / 翻译腔**(倒装、状语前置、长定语堆叠、西式连接词);
> (B) **套路句式 slot 模板**(如"主角眼底的寒芒一闪""反派冷笑一声"——句式+词序+槽位,不只是词)。
> 用 workflow 并行只读审查 5 模块 + 评审挑刺。结论已并入评审修正。

## 1. 结论先行

**现有架构在"词汇/意象"和"粗结构统计(句长/对白比/标点)"上投入充分,但"句法/句式模板层"是盲区。** 具体:
- **genre_template(刚建的)结构性缺失**:纯语义字段,**没有任何句法维**;且 `_distill` 提示词明令"不要任何作者的句长/段落/标点等结构习惯"——把**翻译腔**这种"既属题材又属句法"的东西随结构一起误删了(过度套用 V1)。
- 全架构的"反套路"火力都在**词汇/短语级**(列词、列禁用短语),没有一条是**可泛化的句式模板**——禁了"瞳孔骤然收缩",挡不住"眸光猛地一缩"(同一句式的变体)。

## 2. 覆盖矩阵

| 模块 | 词汇/意象 | 粗结构统计 | (A) 题材句式/翻译腔 | (B) 套路句式 slot 模板 |
|---|---|---|---|---|
| style_genome.syntax | ✓ | ✓ | 部分(sentence_patterns 偏"节奏/逻辑句式",不点翻译腔/倒装) | 部分(形式能装 slot,但提示词不往套路抽,且不挂负面清单) |
| **genre_template(新)** | ✓ | ✗(刻意排除) | ✗(翻译腔被连坐排除) | ✗(anti_patterns 是词汇级) |
| _fingerprint | ✓ | ✓(强项:句长/CV/对白比/hedge) | 部分(hedge 沾边欧化弱断言) | ✗ |
| craft | ✓ | ✓(rhythm 类 + CARD.sentence_rhythm) | ✗ | 部分(anti_trope/dont 是自由文本,非 slot 模板) |

右两列基本"部分/✗"= 用户命中的盲区。

## 3. 提案(已并入评审修正,砍掉过度设计)

**(1) genre_template 加 `cliche_sentence_templates`(B 类,最高优先)**
- **一维字符串数组 + 每条 2 个真实变体**(尖括号只作"此处可换"的视觉提示,**不做词性 schema、不做 pos_slots**——评审:中文无可靠轻量词性标注,槽位 schema 是镀金;writer 末尾朴素短语清单的成功已证明朴素列举够用)。
  例:`"<人物>的<眼睛>骤然收缩(变体:瞳孔骤然收缩 / 眸光猛地一缩)"`。
- **频次是一等公民**(评审补的最大漏):套路 = **高频**,不是绝对禁用。每条带触发阈值(如"同章≥2 次即判套路");偶用一次往往无害。
- **抽取必须从真实语料归纳**:每条模板 2 变体中**至少 1 个是输入语料原句(可定位)**;落不到原句的模板丢弃(防 LLM 把孤例伪装成模板)。复用 craft 的 rhythm/anti_trope 片段语料当素材。

**(2) genre_template 加 `syntactic_patterns`(A 类题材句式/翻译腔,第二切片)**
- 数组 `{rule, example, when}`,专收**题材绑定**句法(译本腔长定语、西式连接词、文言判断句…)。
- **翻译腔不是"一律消除",而是按题材选边**(评审纠正的定性错误):克苏鲁/维多利亚 → 进**正向** syntactic_patterns(它是题材风味);都市爽文 → 进负面清单。选边在蒸馏时按题材定。

**(3) 化解与 V1 的张力(评审的关键贡献,不再嘴上调和)**
- V1:"结构指纹=作者层"。往 genre_template 塞句法看似凿 V1 红线。判据:**跨作者不变性**——
  - 同题材、不同作者间**收敛**的句法 → 题材层(进 genre_template);
  - 同题材内**因人而异**的句法(句长 CV/对白比)→ 作者层(留 fingerprint/genome)。
- **机制保证**:`syntactic_patterns` **只在 multi=True(多作者同题材)蒸馏路径产出**;单作者样本不许抽题材句法。
- **必做验证**:对抽出的每条句式跑**"留一作者"检验**——抽掉任一作者样本仍出现才算题材项,否则判作者私货剔除。→ 把 V1 张力变成可证伪实验。

**(4) 确定性辅助(只取高特异性,评审砍掉低信噪比项)**
- 放 `_fingerprint.py`:西式连接词密度("如此…以至于/与其说…不如说")、抽象施事被动("被一种…所…攫住")、单句"的"≥3 长定语堆叠。
- **砍掉**"句首状语比例""泛被动密度"(中文假阳性极高);套路命中**只数固定锚词同句共现**("瞳孔"+"收缩"同句),**不用通配 `.的(寒芒).{0,2}一闪`**(噪声淹没)。
- 命中率先作**调试可观测指标**,除非消融证明提升判别 AUC,否则不进 compare() 闭环。

**(5) render + V6 旋钮联动**:render_system_prompt 增"句式要诀"(正向,受 genre_strength 调浓度)+"句式负面清单"(受 **novelty/求异度** 调:高求异→硬禁用同章重复模板)。复用 writer.py 末尾"出稿自查命中即换"的写法,把约束粒度从词升到句式。

## 4. 最小可用切片(MVP,只动 2 个文件)
1. `genre_template.py`:加 `cliche_sentence_templates` 字段 + 改 `_distill` 要它产带变体的句式模板(从语料归纳)+ `render_system_prompt` 渲成句式负面清单、接 V6 novelty。
2. `_fingerprint.py`:加"套路模板命中频次/千字"(锚词同句共现法)。
理由:B 类最痛、改动面最小、**命中率降没降一眼可量化**。
A 类(翻译腔 syntactic_patterns + 高特异性确定性指标)放**第二切片**;craft/style_genome/writer/style.py 推到验证通过后。

## 5. 待验证(沿用 V_genre/V2 评测 + fingerprint AUC 双尺子)
- **客观**:复刻"AUC 0.73→0.91"做法,看加"套路命中频次 + 翻译腔指数"后真文 vs 他书判别 AUC 是否再升。
- **生成**:V_genre 三臂上加一臂 **A+句法层**,对照 A 模板,预期**套路轴显著降、克味/新鲜不掉**;确定性命中率与盲评套路轴应相关(双尺子互证)。
- **消融**:cliche_templates 与 syntactic_patterns 各自独立贡献;syntactic_patterns 跑"留一作者"检验。
- **已知局限**:套路是流动的,静态清单会过期,需维护机制(暂记一笔)。

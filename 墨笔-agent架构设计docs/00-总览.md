# 墨笔 · 系统总览

> 一套面向**百万字长篇网文**的 AI 续写工作流：先把已有的 1472 章嚼成结构化记忆，再让 agent 群按记忆推演剧情、模拟角色、写出新章。

## 1 · 设计哲学

**问题**：让 LLM 直接续写一本读了 100 万字的小说会塌——它会记不住伏笔、写偏人物、违反世界设定。
**思路**：不是把更聪明的模型扔进去，而是先把"读者大脑"建模出来——用专门的 agent 把小说拆成可查询的结构化记忆，每次续写时只取**当下应该被想起的部分**注入上下文。

四条核心原则：

| 原则 | 体现 |
|---|---|
| 记忆 > 上下文 | 永不把全文塞进 prompt；只塞与当前任务相关的子图 |
| 多 agent > 单 agent | 抽取 / 评审 / 决策 / 综合各司其职，温度与模型按职责分层 |
| 时序约束 > 自由生成 | 所有事实带 chapter 号；agent 决策时严格按"截至第 N 章"过滤 |
| 流程可溯 > 黑箱 | 每次 LLM 调用入 `LLMCall` 表，附 cost / latency / token；可重放 |

## 3 · 各链路一句话总结

- **抽取**（[02-语料抽取链路](./02-语料抽取链路.md)）：每 5-20 章一批，6 个 agent 顺序跑，cached prefix 复用上下文，全书 ~$5-10。
- **预测**（[03-预测链路](./03-预测链路.md)）：3-stage——发散候选 → 评分收敛 → 流式落章；arc 版做 100+ 章宏观预测。
- **写作**（[04-写作链路](./04-写作链路.md)）：Outline → Writer → 3 Reviewer 并行 → Editor 仲裁 → ReAct 重写最多 3 轮。
- **仿真**（[05-角色仿真链路](./05-角色仿真链路.md)）：每个角色一份 Profile，5-8 人 × 3-5 轮独立决策，ReportAgent 综合成章。
- **疑点**（[02 末尾](./02-语料抽取链路.md#mystery-agent)）：MysteryAgent 跨批维护"读者还在追问的悬念"，追加 / 锐化 / 解决三动作。

## 4 · 技术栈

**后端**
- Python 3.13 + FastAPI + Pydantic + SQLAlchemy
- SQLite + FTS5 trigram + ChromaDB (lazy)
- Qwen3.5-flash (DashScope OpenAI-compatible) — 默认 `MODEL_FAST` / `MODEL_STRONG` 同款，可分层 override
- ThreadPoolExecutor 做多 agent 并行
- SSE 流式（`StreamingResponse`）

**前端**
- Next.js 14 + TypeScript + Antd 5
- React Flow + dagre（人物图 / 流程图）
- 双主题 (modern Sider / classic top-nav) + 双色彩 (dark/light)
- 装饰字体 Ma Shan Zheng + 衬线正文

**模型选型理念**
- 抽取与决策类 → `MODEL_FAST` (qwen3.5-flash, $0.04/$0.42 per M)
- 长文综合 / 评审 → `MODEL_STRONG` (默认同款，可换 qwen-max)
- 强制 JSON 输出全部走 **tool_use forced**（不是 prompt-suffix），可靠性比 JSON-mode 高一档

## 5 · 核心抽象

| 概念 | 落地 | 作用 |
|---|---|---|
| **Cached Prefix** | `llm.cached_block()` | 同一批 LLM 调用复用相同上下文，省 50-80% 输入 token |
| **Chapter-bounded fact** | 所有表带 `chapter` 列 | 严格按 `after_chapter` 过滤，保证 agent 不知道未来 |
| **Tool-forced JSON** | `tool_choice={"type":"tool","name":...}` | 输出 schema 100% 合规 |
| **Audit log** | `LLMCall` 表 | cost / latency / cache hit 可回放 |
| **GraphRAG projection** | `graph/projections.py` | 把 SQLite 行投影成 React-Flow 节点+边 |

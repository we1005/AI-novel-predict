# 墨笔 · 产品介绍页(landing)

可分享的**纯静态**介绍页,对外讲清"墨笔靠先建结构化记忆(读者的大脑)续写百万字长篇"。不接后端、无外链资源(字体走系统中文栈、无 CDN),`index.html` 直接双击即可在浏览器打开。

- **打开**:`open landing/index.html`(或拖进浏览器)。
- **主视觉**:竖排"双墨接笔"——浓墨(原著)在朱砂印「此後·墨筆續」处转花青(墨笔续写);载入时花青列如墨渗般显现。
- **双墨编码**:浓墨=原著 · 花青=AI 续写 · 朱砂=接笔之缝(颜色即信息)。
- **内容取自真实交付**:《天之炽》157→结局260、58.5 万字、104 章、21 agent、4 层记忆;CTA 直达在线 demo。
- **质量**:响应式(移动端竖排回退横排)、键盘焦点可见、尊重 `prefers-reduced-motion`。

设计说明详见提交记录;初版由 frontend-design 技能产出并发布为 Claude Artifact。
